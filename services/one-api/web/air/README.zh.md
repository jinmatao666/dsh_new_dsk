# React 模板

[English](README.md) | 中文

渠道模型发现为可选操作：模型列表为空也可保存渠道。选择来源渠道后，模型定义表单既可选择已保存清单中的建议，也可手动填写模型 ID。保存时将该 ID 关联到所选渠道；上游是否可用由连通性测试单独验证。

## 基本用法

```shell
# Runs the app in the development mode
npm start

# Builds the app for production to the `build` folder
npm run build
```

如需更改默认服务器，请在构建前设置 `REACT_APP_SERVER` 环境变量，例如 `REACT_APP_SERVER=http://your.domain.com`。

开始编辑前，请确认编辑器的保存操作已启用 `Optimize imports` 和 `Run Prettier`。

## 参考

### 管理员编辑用户

完成编辑后点击保存用户会打开密码确认弹窗。取消会保留编辑内容且不提交；保存失败会保留编辑内容并清空确认密码。显示名称写入账户中心档案，缺失映射或写入失败会返回错误。后续档案写入失败时，其他字段可能已经保存。

管理员及自助修改用户名会更新权威登录标识，重复标识会被拒绝。密码、档案和绑定写入失败会返回错误，不再报告成功。邮箱密码重置使用账户中心邮箱标识和产品映射。多字段保存失败时，先前字段可能已经保存，不提供跨数据库回滚。

### 技能包导入

技能元数据编辑器通过 `usage_example` 保存可选的多行使用示例，保存空字符串可清空。技能接口和管理员浏览抽屉返回、展示同一文本；配套桌面版本在描述下展示，无需重新安装技能包。`skills.usage_example` 文本列由现有启动流程中的 `Skill` AutoMigrate 创建。该字段不改变执行指令或附件。

发布、重新上架和回滚已导入版本会保留管理员编辑的显示名称、图标、分类、描述、场景和标签，包括分类关联。这些操作只替换版本内容、附件、版本号及可用状态。导入新包或通过个人技能审核仍是独立的元数据更新；已被覆盖的展示文字不会自动恢复。

管理员可以选择多个 ZIP 文件（每个 ZIP 一个技能）、单个技能文件夹，或直接子文件夹分别包含技能的父文件夹。只要求根目录存在 `SKILL.md`；`manifest.json` 可省略，由服务端规范化。文件夹附件保留相对路径和二进制内容。导入按顺序执行，展示进度和各项成功或失败结果；单个技能包失败不会阻止后续技能包。成功导入后技能保持下架，包括为已有上架技能导入新版本；上架需要管理员操作。重复版本导入被拒绝时，不会下架技能。完成前需保持页面打开，只重试失败的项；已有技能和版本冲突仍由服务端报错。包含多个技能的单个 ZIP 不作为批量容器处理。列表操作保留选中页；搜索或来源筛选变化时回到第一页，最后一页被移除时回到最后一个有效页。

### 技能批量管理

批量管理支持跨页勾选、全选当前页，以及需确认的批量上架、下架和删除。搜索或来源筛选变化会清空选择。私人技能仅支持删除。操作按顺序复用现有权限校验接口，逐项显示结果，失败不阻止后续项，成功项会清除勾选；不提供回滚或自动重试。完成前需保持页面打开。公开技能删除沿用现有软删除行为，不移除桌面端本地安装的文件。批量上架跳过已上架技能，包括存在待发布更新的技能；更新版本需通过版本管理发布。

### 桌面功能可见性

系统设置对临时读取失败重试两次，失败后提供页面内重新加载。鉴权、权限和无效配置错误会直接显示，不自动重试。加载失败时不会显示可保存默认值的表单；离开页面会取消请求。自动重试仅用于读取，不用于保存。

根管理员在系统设置 → 功能设置中配置自动化和连接器入口。外网和内网各自有独立开关，保存在现有 `SystemDeploymentSettings` 选项中。默认在两种环境中开启自动化，仅在外网开启连接器。公开的 `/api/desktop-config` 接口返回允许公开的可见性设置。更新后的桌面端隐藏被禁用的入口且不留占位，并将设置保持在底部；启动、登录和现有鉴权刷新会应用更改。开启内网入口不会绕过外网访问限制，也不会实现真实连接器授权或调度。无需新增数据库表。

### 桌面插件权限

系统设置 → 插件设置将浏览器助手总开关保存在 `SystemDeploymentSettings.plugins.browserAssistant` 中，字段省略时默认开启，仅超级管理员可保存。`/api/desktop-config` 下发校验后的布尔值；配套桌面版本结合个人开关及现有网络限制决定是否允许使用。启动、登录、切回窗口及鉴权刷新后应用更改，不强制中断正在执行的操作。旧版桌面端需要更新后才能执行该权限约束。无需新增数据库表。

### 用户行为画像

点击用户行打开已记录行为画像。弹窗滚动时保留标题和关闭按钮，宽屏并排展示活动构成与趋势，窄屏纵向排列。图表包含接口返回的北京时间日期窗口首尾两天。已记录安装量按用户和技能去重，与可重复下载事件独立展示，不推断安装转化率。已安装技能按下载次数排序，分两列展示，默认显示 10 个并可展开全部；历史安装若没有下载记录，列表中显示 1 次，累计下载量仍只统计实际下载事件。

组织树和角色组织选择器使用同一个数组响应，详见[组织管理](../../docs/role-management.md)。组织读取失败时显示页面内重试状态，不显示零节点计数。
