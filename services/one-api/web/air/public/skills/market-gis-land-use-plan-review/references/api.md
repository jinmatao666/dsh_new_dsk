# GIS_Service 土地利用规划审查接口

- 方法：`POST`
- 路径：`/Analysis.svc/OneKeyAnalysis`
- 默认服务地址：`http://60.191.110.206:38010`；`-BaseUrl` 参数优先，其次使用 `DSH_GIS_SERVICE_URL` 环境变量，均未配置时使用默认地址
- 内容类型：`text/plain; charset=utf-8`
- `GeoJson`：ArcGIS `{ hasZ, hasM, rings }` 对象序列化后的字符串
- `Blxsw`：审查类别，当前默认值为 4
- 固定开关：`IsAnaXzCoverBp=false`、`IsAnaGh=true`、`IsAnaGhWithCZJSKZQ=false`

## 返回数据集

| 返回属性 | 含义 | 可安全解读的字段 |
| --- | --- | --- |
| `YZT_GHSCB` | 规划审查表 | 项目范围的土地利用结构、建设用地管制分区、永久基本农田和重点项目审查结果。 |
| `YZT_GNQMJB_LIST` | 土地用途功能区面积表 | 项目范围与各类土地用途区叠加后的面积结果。 |
