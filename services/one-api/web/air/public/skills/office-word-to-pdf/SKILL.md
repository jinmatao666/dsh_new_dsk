# Word 转 PDF

## 适用场景

- 用户要把一个或多个 Word 文件转换成 PDF，用于打印、发送或归档。
- 不负责改写正文、合并多个 PDF 或对 PDF 再压缩；这些请求应交给对应技能。

## 执行与交互

1. 确认输入是 `.doc`、`.docx` 或 `.docm`。多个候选文件且用户没有说清时，先列出文件让用户确认。
2. 根据下方操作系统说明选择随包入口。Windows 运行 `scripts/invoke.ps1 -InputPaths <文件列表> -OutputDirectory <目录>`，依次尝试 Microsoft Word、WPS 和 LibreOffice；Mac 使用 Python 入口。
3. 每个输入独立转换。输出与原文件同名；重名时自动追加序号，绝不覆盖原文件。
4. 转换失败时保留其他已成功文件，并明确列出失败文件和原因，不把“已复制但未转换”的文件冒充 PDF。

## 交付

- 正式成果仅包含：转换后的 PDF（每份输入对应一份 PDF）。
- JSON、Markdown、转写文本、提取文本、索引、处理日志和临时文件均为内部文件，不进入成果列表，不在最终回复中列作交付。不得默认额外生成 ZIP。
- 仅使用成功返回的 `artifacts` 中真实存在的路径展示成果；失败时说明原因，不猜测文件名、不自行拼接链接。工作台使用的分析视图 JSON 必须内部保留。

## 通用约束

- 输入可以来自工作区外；先使用用户提供的绝对路径。技能安装目录视为只读，所有输出写入用户指定目录或输入文件旁的独立输出目录。
- 不修改、不删除、不覆盖输入文件。除批量重命名的确认执行外，所有产物都使用安全的新文件名。
- 只有命令成功且目标文件真实存在时才能声明完成。错误信息应包含失败文件、原因和下一步，不展示堆栈给普通用户。
- 最终回复先给结果摘要，再给主要产物链接，最后列出必要的限制或失败项。

## 操作系统与运行前检查

- Windows：保留现有 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <技能目录>/scripts/invoke.ps1` 入口及其业务参数。
- macOS：使用 `python3 "<技能目录>/scripts/invoke.py" --check` 检查环境，然后使用同一入口运行。禁止在 Mac 调用 `powershell.exe`，禁止模型临时重写数据解析、接口请求或报告生成脚本。
- Mac 必须后台运行：优先检测 WPS 官方本地 `wpscli`，其次检测 LibreOffice `soffice --headless`。检测 PATH、`/Applications`、用户 `Applications`，支持配置 `WANWEI_WPSCLI_PATH` 或 `WANWEI_SOFFICE_PATH`。使用可运行入口的 Python 3，不因低于 3.10 单独拒绝。运行 `python3 "<技能目录>/scripts/invoke.py" --inputs "<Word文件>" --output-directory "<输出目录>" --converter wps-cli` 可单独测试 WPS；可指定 `libreoffice`。自动模式选择首个检测到的转换器，失败即停止，不静默更换引擎。
- WPS 候选入口依据官方本地 CLI 文档 https://global-static.wpscdn.com/wpscli/SKILL.md ：先检查 `--help` 和 `word2pdf --help`，确认能力后执行 `word2pdf <输入> --output <输出> --json`。退出码 100 表示未登录，101 表示权限不足；明确报告，由用户自行处理，不打开登录或付费链接、不自动安装插件、不调用云端 CLI 或反馈上传命令。旧版本可能没有此能力，禁止猜测 `--convert-to` 等参数。
- 禁止打开 WPS/Word 窗口、使用 System Events/AppleScript 控制桌面、模拟按键/点击或请求辅助功能授权。本包不执行桌面控制，但 WPS CLI 自身是否会因初始化等原因弹窗或抢焦点，尚需 Mac 真机验收；不得声称已保证不抢焦点。如果实测出现窗口或焦点变化，此入口不满足后台要求，停止使用，不转为界面操作。没有可用转换器时明确报错并停止；不自动安装软件、不上传云端。LibreOffice 使用独立转换配置目录，不连接用户已打开的办公应用。
- 禁止猜测 `wpscli --convert-to`、临时编写 AppleScript/ReportLab 转换脚本、安装替代渲染库或提取正文重排来冒充保留原版式的转换。所有转换依据随包入口返回的 `files`、退出码和 `WANWEI_RESULT`；返回文件已检查 PDF 头尾，已有 pypdf 时再检查可解析页数，但这不代表视觉版式已验收。
- 检查失败、路径不可用、依赖安装或输出目录被沙箱拒绝时明确报错并停止；由桌面端处理工具路径、审批与成果链接展示，不静默绕过，不自动下载替代工具。
- 执行必须等待结束，依据退出码及最终 `WANWEI_RESULT` 判断状态；`--check` 仅代表环境检查，不代表业务执行成功。

## 用户可见语言

- 默认以中文回答；成果文件名、报告正文、章节标题、表头、成果说明和处理提示使用中文。用户明确要求其他语言时除外。
- 脚本、命令、参数、接口字段、JSON 键名与协议标识保持原样；英文专有名词和引用原文按需保留，不强行翻译。原文对比不得翻译后再比较。
- 最终回复只列正式成果，并说明真实失败项或限制，不将内部文件作为额外交付。
