# GIS_Service 地质条件分析接口

- 方法：`POST`
- 路径：`/Analysis.svc/OneKeyAnalysis`
- 内容类型：`text/plain; charset=utf-8`
- `GeoJson`：ArcGIS `{ hasZ, hasM, rings }` 对象序列化后的字符串
- 固定开关：`IsAnaXzCoverBp=false`、`IsAnaDzzhyfqk=true`、`IsAnaDzhjtj=true`
- `YfxFieldName`：分区名称字段，默认“分区名称”

## 返回数据集

| 返回属性 | 含义 | 可安全解读的字段 |
| --- | --- | --- |
| `YZT_DZHJTJ_LIST` | 地质环境条件列表 | 项目范围涉及的地质环境条件、等级和重叠面积。 |
| `YZT_DZZHYFQK_LIST` | 地质灾害易发区情况列表 | 项目范围涉及的地质灾害易发分区、等级和重叠面积。 |

## 字段中文映射

| 接口字段 | 中文名称 | 解释 |
| --- | --- | --- |
| `ID` | 记录编号 | 服务内部记录标识，不作为地质评价指标。 |
| `DZHJTJ` | 地质环境条件 | 项目范围所在区域的地质环境条件描述或分类。 |
| `FQMC` | 易发分区名称 | 地质灾害易发性分区的中文名称。 |
| `DJ` | 分区等级 | 地质环境或地质灾害易发性等级；优先结合 `FQMC` 和返回值表述为高、中、低或非易发等级。纯数字代码无法直接对应文字时，写“分区等级 N”，不得写成未知字段。 |
| `ZYMJ` | 重叠面积 | 项目范围与当前地质条件区或易发分区相交的面积。报告中沿用接口及脚本换算后的面积单位。 |

对同一字段在不同返回数据集中的含义按所属数据集限定：地质环境条件列表中的 `DJ` 是地质环境条件等级，地质灾害易发区列表中的 `DJ` 是易发性等级；两类 `ZYMJ` 均为项目与当前图层记录的重叠面积，不能跨图层相加。必须原样保存响应，但用户可见内容不得裸露字段缩写。
