# 技能与专家使用统计

管理后台「使用统计」位于「模型日志」上方，包含技能统计、专家统计、技能明细、专家明细。统计页提供 Top 10、部门汇总与按天/周/月趋势；明细页显示人员、使用时间、名称和部门。

服务启动时通过 GORM `AutoMigrate` 核对并创建 `usage_events` 表，无需手动建表。每条事件使用稳定的 `event_id` 作主键，仅对同一事件的网络重试去重；不同对话轮次、同一轮的多次模型调用均分别计数。

技能事件由桌面端登录用户令牌上报。用户消息中的技能标记记录为 `invocation_type=user_explicit`，模型发出的 `skill` 工具调用记录为 `model_auto`；管理后台将两类合并统计，原始类型保留在表中。专家网站仅在任务提交给执行器后用注册的提供方凭据上报，平台依据已核验的票据用户编号和提供方专家资料写入记录。

`department_id` 可为空，`department_name` 暂时为空；未归属人员在后台显示「未归属部门」。后续接入组织关系时，应在服务端写入事件发生时的部门快照，不接受客户端自报部门。

接口：`POST /api/usage/skill`（用户鉴权）、`POST /api/expert-web/usage`（提供方凭据）、`GET /api/usage/admin/stats` 与 `/details`（管理员鉴权）。查询日期以中国标准时间的自然日为准，最多查询一年。
