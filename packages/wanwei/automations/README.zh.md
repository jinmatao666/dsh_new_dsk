# @deepseek-ai/dsh-wanwei-automations

[English](README.md) | 中文

## 概述

用户可以创建本机任务、暂停任务、立即执行并打开执行会话。任务和运行记录在关闭页面及重启桌面端后保留。桌面端必须保持运行并登录；错过的计划不补跑。现有入口显示及纯内网限制仍由提供方管理；本包不启用云端调度。

## 使用本包

万维桌面产品通过[组合补丁](../../bundle/wanwei-desktop/cordis.patch.yml)挂载本插件。[Host 配置](src/runtime.ts)控制存储、调度间隔、延迟容忍、执行超时和保留数量。

桌面端只显示 Host 已保存的任务，支持启用/暂停筛选、编辑和批量操作。选择已有工作区或本地文件夹以及本地执行时间。确认新任务后保存并启用；编辑保留原启停状态。每次执行新建普通会话。完全访问默认开启且不请求审批；关闭后使用工作区写入与审批，可能使无人值守任务等待处理。请仅使用可信的任务和工作目录；普通对话的默认权限保持不变。

新建菜单提供手动新建、从任务新建和从模板新建。从任务新建打开新对话，在输入框预填 `帮我创建一个定时任务：`；不自动发送消息，也不自动保存定时任务。六个办公模板打开可编辑草稿。保存前须确认说明、工作目录和调度配置。模板不会作为示例任务写入存储。批量操作栏固定在页面底部。

新建控件使用 Lucide SVG 图标，不使用字体字符。下拉箭头在固定尺寸的触发区域中居中，装饰图标不进入可访问名称。紧凑菜单与整个组合按钮等宽，间隔两像素，并保留 Escape 和焦点离开时关闭的行为。

编辑器的工作区菜单向上打开，使用与对话选择器相同的文件夹图标，可超出弹窗且不被裁切。菜单支持搜索及共用本地文件夹选择器，不提供手填路径入口。选择只修改草稿路径，不切换当前对话或修改工作区注册；取消保留原路径。可搜索的模型菜单读取 Host 目录，支持跟随默认模型或保存任务专用模型路由。执行只为该会话选择模型，不修改用户默认值。权限面板内提供完全访问警告和开关；表单不提供启用复选框、常驻审批提示或消息推送控件。运行记录仍支持筛选并打开关联会话。

重复、时间和有效期三个等宽字段向上打开控件。支持间隔、单次、每天、工作日、每周、每双周、每月和每年；已保存的每周五任务继续支持。间隔为从所选开始日期和时间计算的正整数分钟。每周和每双周保留起始星期；每月和每年保留起始日，不存在的日期取当月最后一天。有效期按本地日期计算，包含结束当日。单次执行完成或有效期耗尽后自动暂停；重新启用已过期任务须先修改日期。不解释法定节假日。

编辑器弹层即使渲染在文档 body 下，也保留指向已挂载触发控件的明确关联。因此选择模型、工作区、权限、重复频率、时间或日期会保持功能页和草稿打开。Escape 关闭弹层；外部导航与页面的返回控件保留正常退出行为。

窗口尺寸变化时，任务和运行记录的空提示在筛选栏、表头下方的剩余内容区内垂直居中。

每次执行会话归属所选工作区，同时显示在左侧工作区和运行记录中。本地文件夹在开始执行时注册为工作区。启动时不归档会话；用户手动归档或之前已归档的会话保持归档。历史筛选框在文字和箭头之间保留间距。

每个任务收到通用的前置条件、范围和结果检查指令，以及有上限的顶层目录清单。空目录是事实依据，不直接等于失败：由模型判断任务是否需要输入文件。缺少必要输入记录为待补充，其他未完成工作记录为未完成。指令要求模型不搜索无关目录、不猜临时路径。完全访问仍是完全访问；这些指令不是操作系统文件访问限制。

会话专属 automation_checkpoint 工具将前置条件核对、阶段摘要、真实路径和下一步保存到加锁运行记录及会话日志中，运行记录可展开查看最新进度。智能体轮次结束但没有完成检查点时标记未完成，不判成功。文件任务不得取消已声明的交付要求或无文件报完成。Host 核对工作区内规范路径、普通非空文件及可读性，并用桌面文档助手打开 DOCX、PDF 和 XLSX；缺少解析器时验证失败。其他格式仅做基础文件检查，内容准确性不在保证范围内。documentTool 可覆盖 DSH_DOCUMENT_TOOL；outputCheckTimeoutMs 默认每文件 60000 毫秒。

中断或超时后打开原会话，根据已保存进度和过程文件继续。这是手动继续，不是自动重跑或新的计划执行；继续不会改写原运行记录的终态。过程文件留在工作区中，任务指令要求将它们排除在最终交付清单之外。

任务和记录搜索在顶部原位展开，不增加一行；Escape 清空并收起搜索。台账列保持左对齐和单行，任务长名称截断，窄窗口横向滚动。点击有关联会话的行或按 Enter/Space 打开会话。删除图标请求确认，只移除当前账号非执行中的记录；任务、会话及文件均保留。执行中记录用于阻止重叠执行，因此不能删除。

默认任务文件位于 Harness 主目录下的 automations.json。读取按账号隔离；修改使用文件锁和原子替换。存储异常会明确报错，不重置任务。修复损坏文件或遗留的同名锁文件前须关闭桌面端，并在修复前保留副本。

停用本插件的配置项会移除其入口；不需要停用其他业务插件。共用鉴权、渲染和侧边栏服务仍由各提供方负责。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

Client 拥有选择状态和提示，通过鉴权的本机 RPC 读取已提交数据，编辑后拒绝过时的轮询响应。它使用 feature-panels 提供展示和导航。控制器在侧边栏导航或退出登录时关闭页面。

[Host 运行时](src/runtime.ts)持久化领取到期任务后调用现有会话控制器。它在启动前推进下次执行时间，并阻止同一任务重叠执行。成功依据已完成回合记录，而不只看空闲状态；超时、中断和执行失败均会记录。卸载停止调度并取消所属执行。

</details>

<a id="model-experience"></a>
## Model Experience

间接：调度器把用户编写的任务说明提交给普通会话控制器；现有 Agent 和模型提供方负责请求组装、工具和 token 消耗。

#### KV Cache effect

每次执行新建会话；本包不复用以前的任务对话，也不修改提供方的缓存策略。

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- 时区变化跟随桌面端本地时钟；调度器不单独保存任务时区。
- 不提供云端执行或错过计划补跑。退出登录停止接收执行；超时默认六十分钟，包含等待任务输入的时间。仍可手动停止，超时记录保留进度并明确说明超时原因。
- 记录保留会话链接，不单独复制产物。删除任务不删除会话或工作文件。
- 账号隔离使用本机登录用户名；不同部署需要独立的 Harness 主目录。
- 真实模型及 UOS、macOS、Windows 原生验收属于部署检查；自动集成测试替代外部模型响应。
