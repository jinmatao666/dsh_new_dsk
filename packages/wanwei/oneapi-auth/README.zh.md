# @deepseek-ai/dsh-wanwei-oneapi-auth

[English](README.md) | 中文

## 概述

在账户设置中成功退出登录后，设置面板自动关闭并显示登录页。退出失败时保留面板并显示错误。

检查登录状态和退出登录后使用相同的表单与固定高度的内容区域。登录页每次显示时重新计算缩放，字体布局不继承工作区设置。

桌面登录布局使用以 Windows 为基准的分栏尺寸和明确的文字行高。字体仍使用本地系统字体，因此字形渲染可能不同。WebKit 使用带前缀的背景模糊规则。

用户登录配置的 OneAPI 服务并使用账户获准的模型。桌面读取后台管理的模型目录，不提供本地提供方编辑。Host 还会获取已上架专家资料与一次性网站票据，并把 OneAPI token 留在 Client 之外。

## 使用本包

万维产品组合包挂载 Host 和 Client 两部分。浏览器只接收认证状态和模型标识，不接收密码或生成令牌。

版本设置位于账户之前，在桌面桥存在时显示当前版本、自动检查开关和手动检查按钮。插件持有的监视器在独立弹窗中展示下载和安装进度，不依赖设置页是否打开。收起下载进度不会取消下载，可在版本页重新打开。大小未知时显示不确定进度，安装进度不可关闭。原生下载和安装确认保持不变。Host 的父进程专用更新协议拒绝忙碌的 Agent、维护、工具、作业和已登记的自动化区间，再等待整个插件树清理后确认退出。纯浏览器部署没有安装控件。原生调度、签名配置和平台验收由[桌面壳](../../../products/wanwei-desktop/README.zh.md)持有。

### 配置

知识库上传使用有界 RPC 分片，每个已挂载的认证插件最多持有一个私有临时文件。`knowledgeUploadIdleTimeoutMs` 默认值为 900000 毫秒；空闲上传会过期，完成、失败、显式取消及插件卸载均会删除临时数据。multipart 转发时 OneAPI 凭证保留在 Host。上传和解析限制详见[知识库包](../knowledge-base/README.zh.md)。

托管资源通道通过仅监听回环地址的代理和 WebSocket 路由复用已认证的 OneAPI 来源，无需新增公网端口。后台设置选择 `transport: tunnel`；省略接入方式时使用独立正向代理。可选直连主机扩展 NO_PROXY。HTTPS 目标仍校验证书，但 HTTP/WS 入口不保护中转凭证或连接信息。切换来源会撤销已有托管连接，插件卸载会关闭监听器。部署和验收详见[资源指南](../../../products/wanwei-desktop/resource-relay/README.zh.md)。

网络环境及各环境独立的自动化、连接器入口可见性由配置的后台系统设置决定。Host 在登录前和认证刷新时读取 `/api/desktop-config`，并通过 `wanwei-network.mode` 缓存后台已确认的策略。窗口聚焦、页面恢复可见和既有五分钟认证计时器也会刷新。缺少功能配置时默认两种环境均开启自动化、仅互联网开启连接器；显式无效开关会拒绝刷新，不替换已提交的 Client 状态。配置读取失败时阻止登录，不假定为互联网。两种模式都允许专家服务请求、本机调度和已安装 SkillHub 技能；可用性由实际服务请求决定。`serviceTimeoutMs` 限制部署与专家请求时长，默认 15000 毫秒。纯内网模式仍限制公网搜索、通用公网网页读取及通用公网 HTTP(S) 链接。私有地址、本地 DNS 名称及配置的 OneAPI 来源仍可访问。额外内网域名需要明确补充分类规则。

旧功能配置对象仅缺少 `knowledgeBases` 字段时，各环境的知识库入口默认开启。原有自动化、连接器开关和明确关闭的知识库开关保持不变；null 或非布尔值仍校验失败。OneAPI 配置读取和管理员设置页采用相同规则，管理员保存前不改写存储配置。

版本设置仅在当前页面点击手动检查后展示检查结果，重新打开页面清空结果显示。不在检查按钮下常驻重复的下载安装说明。更新配置缺失和桥接错误仍会显示。无更新响应明确说明未发现可用更新并给出当前版本，不声称后台已有发布版本。自动检查和原生确认弹窗保持不变。

忘记密码通过独立弹窗读取后台运维联系人。短信和扫码登录只提示未开放，不替换账号登录表单。登录卡片保留既有尺寸，不提供注册或模拟认证控件。

部署确认后的网络快照包含 `directInternet`。内网确认复用资源路由缓存的直连检测，不启动隧道。关闭检测、使用离线资源或检测失败时返回 false；外网模式返回 true。Client 校验并发布该结果，供自动化和连接器判断入口可用性，不改变管理员可见性配置或原生网络模式。

内网资源配置在后台 wheel 依赖包与正向代理之间二选一，不跨来源兜底。离线模式配置 pip 的 `PIP_NO_INDEX` 和后台 wheel 链接；中转模式配置遵循代理设置的子进程客户端。自动检测要求所有 HTTPS 检测地址在并发的 2.5 秒内返回 204，结果缓存 60 秒。Shell 执行前每分钟至多刷新一次部署设置，刷新失败时拒绝启动新命令。已运行的子进程保留原环境。详见[资源配置与验收](../../../products/wanwei-desktop/resource-relay/README.zh.md)。

内网中转模式下，使用默认索引的 `python -m pip download/install` 依次尝试华为云、清华和官方 PyPI。每个源的完整尝试限时 30 秒，pip 不做连接重试。仅可识别的网络或包版本不可用错误触发下一个源；权限、构建、参数和完整性错误直接停止。所有尝试继承所选网络路由，回退不会绕过中转。显式索引或代理参数、`--no-index` 本地安装保持原行为。进程级 Python 模块覆盖层不修改已安装的 pip 或全局配置。直接使用 `pip` 启动器、隔离 Python（`-I`/`-E`）或覆盖 `PYTHONPATH` 时不经过顺序封装。不提供后台界面；`pipMirrorUrls` 和 `pipMirrorAttemptSeconds` 属于产品插件配置字段。离线资源和外网模式不启用封装。

对可识别的 Bash、PowerShell 和终端结果区分模块缺失、连接失败和依赖源未找到包版本，保留原始输出并追加中文说明。托管回退成功后不再为之前失败的尝试追加提示，之后其他命令的失败仍可识别。模型被要求保留警告图标，明确说明纯内网模式和任务无法继续，简短解释实际原因，不输出处理建议或大段原始报错。依赖名称来自本次命令和失败日志，无法确认时使用通用名称。仅在必需依赖仍无法获取时停止依赖它的步骤。权限和语法错误不被归类为网络失败。

镜像策略保存在生成的 Python 入口旁，不通过父进程 `DSH_*` 变量传递，因此生产子进程的环境清理既保留凭证隔离，也不会移除镜像配置。DLL 加载诊断识别为本地依赖缺失，而不是下载失败。中转指引要求如实报告失败或未完成的用户指定验证；替代检查不能证明原验证通过。

这是诊断反馈，不是防火墙或 Shell 沙箱。无法识别的报错不追加自动依赖说明。依赖提示段落在后续提示词组装时跟随后台已确认的环境，历史消息不被改写。互联网模式不增加依赖提示段落或反馈。助手标题、简洁程度和重试决策由模型指引控制，不是确定性的回复模板。

[产品补丁](../../bundle/wanwei-desktop/cordis.patch.yml)提供提供方路由和生成令牌引用。Host 优先使用显式 OneAPI 地址，其次读取启动环境中的 `DSH_ONEAPI_URL`，最后使用本地开发地址。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `baseURL` | `DSH_ONEAPI_URL`，其次 `http://127.0.0.1:3000` | 不含 `/v1` 的显式 OneAPI 地址优先于启动环境。 |
| `provider` | `dsh-server` | 受管理的 DSH 模型提供方路由。 |
| `credentialRef` | `DSH_ONEAPI_TOKEN` | 已存储的生成令牌引用。 |
| `tokenName` | `DSH Desktop Auto Token` | 自动创建的 OneAPI 令牌名称。 |
| `defaultModel` | 可选 | 首选默认模型标识。 |
| `defaultInput` | `[text]` | 模型标识公开的输入模态；仅在支持时启用图像。 |
| `installId` | 可选 | 新安装后要求登录的构建标记。 |
| `developmentBypass` | `false` | 仅供源码开发环境跳过登录浮层。 |

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

回环 Host 向 OneAPI 交换凭据，将生成令牌交给 DSH 凭据提供方，读取可用模型并配置受管理的 pi-ai 提供方。Client 通过 slot 渲染登录页、账户区和只读模型区。Host 使用同一已登录令牌调用配置的 `oneapi-bailian` 搜索提供方，并申请一次性专家打开票据。只有网站地址与短时票据传给 Client。

主机还会向 OneAPI 上报由官方注入器成功解析的技能引用，以及模型每次发出的 `skill` 工具调用。服务端分别保留 `user_explicit` 和 `model_auto` 类型，管理员统计将两类合并。同一事件的网络重试由稳定事件编号去重，不会合并不同调用。桌面进程运行期间会在内存中重试；退出前仍未送达的事件不会在重启后补报。

</details>

<a id="model-experience"></a>
## Model Experience

### 受管理的模型请求

#### What the model sees

`dsh-server` 提供方仅提供已登录 OneAPI 账户获准的模型。登录状态和生成令牌不会加入模型提示词。

#### Token effect

登录和读取模型目录不消耗模型 token。用户请求通过所选模型及标准 DSH LLM 提供方处理，并使用通常的用量统计。

#### KV Cache effect

认证本身不改变提示词或缓存键。模型选择和后续请求遵循通常的提供方缓存行为。

### 受管理的网页搜索

#### What the model sees

`oneapi-bailian` 搜索提供方通过现有 DSH 网页工具路径返回结构化检索来源。模型收到真实 HTTP(S) 网址和在相关事实旁引用的指引；搜索卡片也提供可点击来源。没有来源时明确提示无法核验，不合成来源元数据。后台选择的搜索模型和令牌不作为提示词文本出现。HTTP 400 失败显示受限的错误代码，并解释可识别的端点或流式协议不匹配，不回显原始上游诊断。工具要求模型停止重复搜索并告知后台配置问题；这是模型指引，不是强制重试锁。

#### Token effect

搜索请求使用已配置的 OneAPI 服务。当 agent 使用结果时，工具结果 token 按通常方式进入模型上下文。

#### KV Cache effect

不同搜索结果可能改变后续提示词及缓存复用；本包不管理模型缓存。

### 纯内网依赖反馈

#### What the model sees

仅纯内网模式在系统提示词中增加依赖处理指引。显式资源配置按所选来源替换通用指引：离线模式禁止换源或使用公网包地址，中转模式禁止回退离线包。识别到依赖缺失或下载失败时，通过普通工具结果返回中文说明，模型和对话界面均可看到。下载成功不追加失败说明。不插入独立弹窗或伪造的助手消息。

#### Token effect

内网指引和追加的工具反馈按通常方式消耗上下文 token。互联网模式不增加这些内容。

#### KV Cache effect

后台确认的环境变化会改变依赖提示段落，可能影响前缀缓存复用。本包不管理模型缓存。

### 校验最终文件交付

#### What the model sees

Host 提供 `deliver_files`，在最终回复前声明完整的最终成果清单，排除中间文件。工具校验普通文件，解析工作区相对路径，并按文件系统身份去重。空清单只清空文件交付，不清空文字答案。纯文字任务可以不调用，也可以声明空清单。文件登记不追加轮次结束提醒或后续请求；最终回复包含用户要求的答案，而不是文件清单确认。

#### Token effect

静态指引、工具 schema 和文件路径结果消耗普通上下文 token。文件登记不会在答案完成后强制增加一次请求。

#### KV Cache effect

静态指引可复用提示前缀。交付路径随任务变化。

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- 模型发现、受管理搜索和专家目录需要可访问的 OneAPI 服务。桌面没有本地编辑提供方的兜底方式。
- 资源路由覆盖 pip wheel 和遵循代理环境的子进程客户端，不覆盖浏览器流量、原生 PowerShell 下载或 Node fetch；它不是网络沙箱。不提供代理凭证、源码包、系统软件包及离线 npm 包。内网 OneAPI 流量绕过 Shell 代理。公网搜索与链接限制仍独立生效。
- 搜索来源需要更新后的 OneAPI 转发层及公开百炼原生生成端点的渠道，不能只有兼容对话端点。模型是否遵守引用指引仍需真实服务验收；有链接并不代表事实已经核实。
- 独立专家打开需要另行部署 OneAPI `/api/expert-web` 接口和数据库表；普通登录接口不包含该能力。
- 网站票据和子 Webview 权限仍需真实服务与跨平台桌面验收。
- 最终交付校验文件存在性，不校验文档质量或用户意图。模型必须直接调用工具并提供正确的最终清单；嵌套调用不会声明 UI 清单。安装版桌面端与真实模型仍需验收。
