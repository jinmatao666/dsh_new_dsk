# @deepseek-ai/dsh-wanwei-knowledge-base

[English](README.md) | 中文

侧栏入口遵循后台共用排序及当前网络环境的显示开关，参见[部署策略](../oneapi-auth/README.zh.md)。

运营版维护者申请发布订阅知识库前，保存每个文件的浏览、问答和下载三项单价。各单价受管理员设置的每文件上限约束，表单在对应标签下方显示上限。审核通过后，可在桌面端「系统设置 → 积分与用量 → 知识库积分设置」修改。所有者可从个人库撤回公共或订阅发布，撤回后取消共享与订阅访问，原库和文件继续保留。订阅者确认价格后预览或下载。付费预览覆盖同一文件 24 小时内的重复打开。知识库页面问答只结算最终回答实际引用的去重文件。订阅者扣分与维护者收益同时入账。结算失败时暂缓交付回答，并提示清空会话后重试。单价和结算记录以百分之一积分为单位。付费订阅问答在可获取 RAGFlow 最终溯源的知识库页面完成。

## 概述

此 Client 插件增加由管理员控制的知识库入口。OneAPI 负责授权、本地记录和 RAGFlow 凭据；浏览器仅接收当前用户已授权的知识库元数据、文档元数据、解析预览文本、可下载文件字节、已保存的问答记录、回答以及可定位引用。

## 使用此包

在 `dsh-wanwei-oneapi-auth` 和 `dsh-wanwei-feature-panels` 后挂载此插件。在 OneAPI 服务端配置 `RAGFLOW_BASE_URL` 和 `RAGFLOW_API_KEY`。每个新对话创建隔离的 RAGFlow 聊天助手和会话。知识库问答栏可清空当前用户在打开知识库中已保存的问答，做法是替换对应的 RAGFlow 会话。

桌面端个人知识库仅对所有者可见，管理员与超管也只看自己创建的；超管仍可在管理工作台目录查看全部个人库。共享知识库对所有者以及 OneAPI 中获得用户或部门授权的成员可见。已上架的共性知识库对全体用户可见。管理工作台为「个人知识库」加各已创建分类。桌面侧栏固定显示「个人知识库」和「订阅知识库」（无库时显示「暂无知识库」）；「公共知识库」合并全部无需授权的公开库（有库才显示）；「订阅知识库」只列审核通过后的订阅库（不含自建）。FeaturePanel 顶栏通过 `headerArt` 使用暂存的 `/knowledge-covers/hero-banner.png`。授权分类名称不作为侧栏分组；授权库通过侧栏「知识库广场」入口发现（入口底板使用暂存的 `/knowledge-covers/plaza-entry.png`，文案叠在图上），广场以专家与技能目录的视觉体系呈现资源中心页头、图片卡片、状态徽标和自适应详情。个人资料图标、PDF 图标与时钟使用 `/knowledge-covers/` 下的 PNG 切图，分组、问答开关及公共、订阅库的默认图标使用清晰的 SVG，后两者采用带地球或书签标识的立体书册。侧栏条目和紧凑的当前库信息栏优先使用已保存的知识库封面。广场入口使用原有立体书册与背景 PNG。自建授权库在广场标「我的」并排在列表后面，能力与「已订阅」相同（可问答、可打开文件），不进侧栏订阅区。审核通过后他人库仍留在广场（可看订阅人数）并进入「订阅知识库」。广场详情左栏为目录与订阅状态，右栏为知识问答；已订阅或「我的」时可点击文件打开与内容列表相同的预览。打开已订阅（非自建）库可「取消订阅」；自建库不显示该按钮。上传文件不得超过 20 MB。管理工作台的新建和编辑对话框可以附上、更换或清除可选封面。桌面端新建对话框暂不显示封面上传。广场卡片和详情使用已保存的封面；知识库没有封面时仍用预制的自然资源图片。新建对话框中，任何已登录用户既可新建空白 RAGFlow 知识库，也可关联 `{RAGFLOW_BASE_URL}/api/v1/datasets` 已列出的知识库（与知识库管理平台同源）；已绑定到本地库的项不会出现在选择列表中。

桌面页面默认关闭问答，内容区铺满宽度。侧栏搜索框位于个人、公共和订阅分组上方。三个分组采用靛蓝、青绿和紫罗兰色的低圆角梯形页签，收起时保留连续底边；展开后显示白色条目，选中项用对应颜色的边框标记。主题强调色为 `#0865F2`。维护者、更新时间、文件数量和大小采用紧凑的两列文字排版。侧栏每张知识库卡片展示名称、最多两个标签、维护者、更新时间、文件数量和文件大小。个人入口始终显示库所有者为维护者，包括发布待审核或被驳回时。运营版审核通过的公共与订阅入口显示「万维」。其他版本的公共与订阅入口在外网显示「万维」，内网显示创建人。点击名称或信息区选择知识库。名称旁的详情箭头展开或收起描述，订阅知识库同时展开或收起订阅量与现有累计 `visit_count`（授权打开与使用次数）。列表在固定的知识库广场入口上方滚动。这些详情默认收起，展开后位于两列基础信息（维护者、更新时间、文件数量、文件大小）下方，先显示描述，再用同样的文字排版显示订阅统计。标签和基础信息始终显示。切换知识库会收起所有详情，返回之前的知识库也不恢复展开状态。新建个人知识库时可填写逗号分隔的标签，保存在管理工作台共用的 `tags` 字段。卡片右上角的问答图标按钮打开或关闭该库问答栏，打开时显示高亮的按下状态；问答打开时文件列表只显示一列，并隐藏分页条以保留设计稿中的双栏工作区，且不再有可拖动的分隔条。铺满侧栏顶部的搜索框按名称过滤知识库并展开命中的分组。内容工具栏提供文件名称搜索和按上传时间的最新/最早排序；问答关闭时，列表按顶层文件夹或文件分页（每页 12 项），底部分页条按设计稿（`第 x 页 / y`、上一页/下一页、页码、`跳至` 输入框）；内容列用纵向 flex，文件列表单独滚动、分页条钉在底部；列表非空时即显示分页条，只有一页也显示。面板通过 `bodyClassName: dsh-knowledge-host` 收成满高，避免桌面 WebView 裁掉分页。知识库广场将精选知识库及总数在标题栏内水平、垂直居中，置于卡片列表滚动区域外。侧栏的个人、公共和订阅分组默认展开，可分别收起。知识库广场主页采用等尺寸图片卡片，封面清晰显示，配白色状态徽标和已保存的收藏状态。每页 10 张卡片分页；目录有条目时即显示分页条（只有一页也显示），分页条作为广场壳的 flex 子项钉在列表下方，避免短高度宿主把分页裁进收缩的目录里。每张文件卡片展示上传时间和创建人。OneAPI 在文件上传或复制到知识库时记录创建人；调用者自己的文件，以及记录创建人之前上传的文件，不显示创建人。

输入框工具行提供「知识库」开关。开启后弹出选择面板，分组方式与桌面侧栏一致（个人知识库、公共知识库、订阅知识库），可跨分组多选，最多 20 个。插件通过 `retrieval-scope` 操作把当前会话的选择同步到 Host，并在首次发送新建会话时转交给新会话。关闭开关会隐藏选择面板并清除该会话的检索范围，之后的问答不受影响。部署在当前网络下隐藏知识库时，开关也不显示。

桌面文件和文件夹采用自适应多列卡片，置于带低梯形标题的白色内容面板。卡片在名称和现有属性旁展示放大的封面，配文件类型色边框和轻阴影。个人库的空文件夹提供删除按钮，需确认后删除；有文件或子文件夹时须先手动清空，后端会再次检查。打开问答后，文件和文件夹切换为带细分隔线的单列列表。文件名可换行完整显示。解析失败的文件在桌面列表中显示常规文件类型。PDF 先显示蓝色占位图。上传后，OneAPI 用 Poppler 异步生成首页并将 JPEG 存入数据库。封面生成后，当前页的 PDF 卡片从桌面服务加载已保存的图片。窄窗口显示缩小的 PDF 封面。未保存封面的历史文件和生成失败的文件继续显示占位图。图片、音频和 Word 各有对应的封面图案。PDF 预览框使用蓝色边框和蓝底 P 标识。预览不影响模型输入。

运维版中，个人知识库通过紧凑的「发布」菜单申请公共或订阅共享，无需选择目标分类。提交后由管理员审核，待审或驳回时不共享内容，状态与驳回原因刷新后保留。通过后只为同一知识库设置共享范围，保留个人入口与所有者编辑能力。公共库同时出现在公共知识库中；所有者发布的订阅库同时出现在订阅知识库和广场中，其他用户仍需订阅获批才能读取。政务版拒绝发布申请。

## 模型体验

### 输入框知识库检索

#### 模型看到的内容

当前会话设置了知识库范围时，`dsh-wanwei-oneapi-auth` Host 插件会在每个用户轮次的第一步之前，通过 OneAPI `POST /api/knowledge-bases/retrieval`（RAGFlow `POST /api/v1/retrieval`）按用户问题检索切片。它在问题之后记录一条来自 `wanwei-knowledge-retrieval` 的 `notice` 用户消息，内容为编号切片、所属文件名和知识库名，以及注明出处的要求。检索无结果或失败时改为记录一句简短说明。回答由会话自身的模型生成，不经过 RAGFlow 聊天助手。

#### Token 影响

每个设置了范围的用户轮次最多增加 `knowledgeRetrievalMaxChars` 个字符的切片文本和一段固定说明；未设置范围的轮次不增加内容。

#### KV Cache 影响

检索消息追加在用户消息之后，轮次之前的前缀仍可缓存。

### 浏览器发起的知识对话

#### 模型看到的内容

RAGFlow 接收所选数据集、用户问题和该对话的 RAGFlow 历史。Harness Agent Loop 不接收这些内容。在 CreateChat 或 UpdateChat 之前，OneAPI 先检查该数据集是否已有可检索切片：仍在解析时以正常回答返回「文件正在解析，请稍后重试」；切片数为零（含解析完成但未产出切片的文件）时返回「知识库尚无可检索内容，请等待文件解析完成后再试」，而不是把 RAGFlow 网关错误 `doesn't own parsed file` 抛给前端。完成的回答最多展示三条带问号的关联问题，助手品牌在 logo 旁显示为「万维Buddy」。

#### Token 影响

Token 使用由 RAGFlow 聊天助手及其配置模型负责。

#### KV Cache 影响

每个知识对话拥有独立的 RAGFlow 聊天助手和会话，因此缓存不会跨对话复用。

## 已知限制与延期工作

- 创建对话框尚未提供用户及部门授权编辑；数据库和 API 已接受管理流程写入的授权记录。
- 封面上传仅在管理工作台的新建和编辑对话框中。桌面端新建暂不显示；桌面仍会在广场和已打开知识库标题旁展示已保存的封面。
- 上传成功后由服务端异步启动 RAGFlow 解析；桌面页面不提供手动重新切片。单击打开预览。桌面应用将原文件保存到「下载」文件夹，并在预览内显示结果。在「个人知识库」文件列表空白处右击提供「新建文件夹」，与上传菜单复用当前目录下的新建弹窗。在「个人知识库」中右击文件会选中并仅提供删除；「公共知识库」与「订阅知识库」不提供任何文件右键操作。删除会调用 RAGFlow 文档删除接口。图片使用原文件 blob；PDF 用 pdf.js 渲染以便问答引用按 RAGFlow 切块坐标高亮（摘录文本层搜索作兜底）。文件下载走二进制 Fetch，不再经 JSON 字节数组。纯文本使用下载字节；其他类型回退到 RAGFlow 切片文本。回答把 `##i$$` / `#i$` / `[ID:i]` 标注换成对应 RAGFlow `reference` 切块的蓝色序号引用，不会在文末另行添加来源列表。
- 仅「个人知识库」显示上传入口；菜单保留「本地文件」、「网页链接」（换行分隔的 http(s) URL，最多 10 条；客户端正则校验后由 OneAPI 抓取页面并以 HTML/PDF 经 `POST .../web-links` 上传）与「录音纪要」（浮动 MediaRecorder 面板；Client 转为单声道 16 kHz WAV 后 POST `/api/desktop-knowledge-recording-minutes`，由 Host ASR + 聊天起草逐字稿/速览/纪要，再上传配对的 `录音纪要_….md` 与 `.wav`；OneAPI 对音频跳过 RAGFlow 解析）。打开任一配对文件使用双栏纪要预览并支持播放。「公共知识库」与「订阅知识库」隐藏上传按钮。「本地文件夹」选择目录并按相对路径上传其中的文件。文件夹卡片和文件卡片对齐到同一网格。文件卡片内显示缩略图、文件名、类型或解析进度，并在有记录时显示上传时间。总文件数显示在工具栏的「内容」旁。点击文件夹只显示该目录内容，可通过路径导航和返回上级操作退出。上传目标为当前目录，本地文件夹上传也会保留其相对子目录。「新建文件夹」在 OneAPI 保存当前目录下的空文件夹，刷新后仍显示，并与同名上传路径合并。文件夹路径在每个知识库内唯一；空路径段、点路径段、反斜杠、控制字符、超过 128 字符的路径段和超过 512 字节的路径会被拒绝。笔记、腾讯文档和从个人知识库导入入口保持隐藏。

广场卡片与详情页的小爱心按登录账号保存在 OneAPI，刷新或重新登录后恢复；喜欢不会授予知识库访问权限。

本地更新源码后，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\wbuddu\scripts\start-wanwei.ps1 -Refresh`，再在桌面页面按 Ctrl+F5。刷新模式会编译知识库及认证 TypeScript 程序、打包客户端、构建 OneAPI 并重启后端和桌面服务；默认调用会复用现有服务。两种启动方式都会在检查服务前将产品 Web 图片同步到 `apps/web/dist`，可恢复官方 Web 重建后缺失的图片。

## 构建品牌

产品自有名称和图片读取构建生成的品牌快照，通过[桌面品牌配置](../../../products/wanwei-desktop/branding/README.zh.md)选择；协议标识、凭据和用户内容保持不变。
