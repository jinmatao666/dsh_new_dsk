# @deepseek-ai/dsh-wanwei-knowledge-base

[English](README.md) | 中文

## 概述

此 Client 插件增加由管理员控制的知识库入口。OneAPI 负责授权、本地记录和 RAGFlow 凭据；浏览器仅接收当前用户已授权的知识库元数据、文档元数据、解析预览文本、可下载文件字节、已保存的问答记录、回答以及可定位引用。

## 使用此包

在 `dsh-wanwei-oneapi-auth` 和 `dsh-wanwei-feature-panels` 后挂载此插件。在 OneAPI 服务端配置 `RAGFLOW_BASE_URL` 和 `RAGFLOW_API_KEY`。每个新对话创建隔离的 RAGFlow 聊天助手和会话。知识库问答栏可清空当前用户在打开知识库中已保存的问答，做法是替换对应的 RAGFlow 会话。

个人知识库仅对所有者可见；管理员桌面可查看全部未归类个人库。共享知识库对所有者以及 OneAPI 中获得用户或部门授权的成员可见。已上架的共性知识库对全体用户可见。管理工作台为「个人知识库」加各已创建分类。桌面侧栏固定显示「个人知识库」和「订阅知识库」（无库时显示「暂无知识库」）；「公共知识库」合并全部无需授权的公开库（有库才显示）；「订阅知识库」只列审核通过后的订阅库（不含自建）。授权分类名称不作为侧栏分组；授权库通过侧栏「知识库广场」发现，广场以专家与技能目录的视觉体系呈现资源中心页头、图片卡片、状态徽标和自适应详情。自建授权库在广场标「我的」并排在列表后面，能力与「已订阅」相同（可问答、可打开文件），不进侧栏订阅区。审核通过后他人库仍留在广场（可看订阅人数）并进入「订阅知识库」。广场详情左栏为目录与订阅状态，右栏为知识问答；已订阅或「我的」时可点击文件打开与内容列表相同的预览。打开已订阅（非自建）库可「取消订阅」；自建库不显示该按钮。上传文件不得超过 20 MB。管理工作台的新建和编辑对话框可以附上、更换或清除可选封面。桌面端新建对话框暂不显示封面上传。广场卡片和详情使用已保存的封面；知识库没有封面时仍用预制的自然资源图片。新建对话框中，任何已登录用户既可新建空白 RAGFlow 知识库，也可关联 `{RAGFLOW_BASE_URL}/api/v1/datasets` 已列出的知识库（与知识库管理平台同源）；已绑定到本地库的项不会出现在选择列表中。

桌面页面默认关闭问答，内容区铺满宽度。侧栏每张知识库卡片展示名称、描述、维护者、更新时间、文件数量和文件大小，不显示封面图片、分类、归属徽标和订阅人数；卡片右上角的问答图标按钮打开或关闭该库问答栏，打开时显示高亮的按下状态；问答打开时文件列表只显示一列，且不再有可拖动的分隔条。侧栏分组上方的搜索框按名称过滤知识库并展开命中的分组。内容工具栏提供文件名称搜索和按上传时间的最新/最早排序；列表按顶层文件夹或文件分页（每页 12 项），底部分页条对齐技能市场样式（总页数、页码按钮、跳转）；内容列用纵向 flex，文件列表单独滚动、分页条钉在底部。面板通过 `bodyClassName: dsh-knowledge-host` 收成满高，避免桌面 WebView 裁掉分页。每张文件卡片展示上传时间和创建人。OneAPI 在文件上传或复制到知识库时记录创建人；调用者自己的文件，以及记录创建人之前上传的文件，不显示创建人。

输入框工具行提供「知识库」开关。开启后弹出选择面板，分组方式与桌面侧栏一致（个人知识库、公共知识库、订阅知识库），可跨分组多选，最多 20 个。插件通过 `retrieval-scope` 操作把当前会话的选择同步到 Host，并在首次发送新建会话时转交给新会话。关闭开关会隐藏选择面板并清除该会话的检索范围，之后的问答不受影响。部署在当前网络下隐藏知识库时，开关也不显示。

## 模型体验

### 输入框知识库检索

#### 模型看到的内容

当前会话设置了知识库范围时，`dsh-wanwei-oneapi-auth` Host 插件会在每个用户轮次的第一步之前，通过 OneAPI `POST /api/knowledge-bases/retrieval`（RAGFlow `POST /api/v1/retrieval`）按用户问题检索切片。它在问题之后记录一条来自 `wanwei-knowledge-retrieval` 的 `notice` 用户消息，内容为编号切片、所属文件名和知识库名，以及注明出处的要求。检索无结果或失败时改为记录一句简短说明。回答由会话自身的模型生成，不经过 RAGFlow 聊天助手。

#### Token 影响

每个设置了范围的用户轮次最多增加 `knowledgeRetrievalMaxChars` 个字符的切片文本和一段固定说明；未设置范围的轮次不增加内容。

#### KV Cache 影响

检索消息追加在用户消息之后，轮次之前的前缀仍可缓存。

### 浏览器发起的知识对话

#### 模型看到的内容

RAGFlow 接收所选数据集、用户问题和该对话的 RAGFlow 历史。Harness Agent Loop 不接收这些内容。在 CreateChat 或 UpdateChat 之前，OneAPI 先检查该数据集是否已有可检索切片：仍在解析时以正常回答返回「文件正在解析，请稍后重试」；切片数为零（含解析完成但未产出切片的文件）时返回「知识库尚无可检索内容，请等待文件解析完成后再试」，而不是把 RAGFlow 网关错误 `doesn't own parsed file` 抛给前端。完成的回答最多展示三条带问号的关联问题，助手品牌在 logo 旁显示为「万维Buddy」。

#### Token 影响

Token 使用由 RAGFlow 聊天助手及其配置模型负责。

#### KV Cache 影响

每个知识对话拥有独立的 RAGFlow 聊天助手和会话，因此缓存不会跨对话复用。

## 已知限制与延期工作

- 创建对话框尚未提供用户及部门授权编辑；数据库和 API 已接受管理流程写入的授权记录。
- 封面上传仅在管理工作台的新建和编辑对话框中。桌面端新建暂不显示；桌面仍会在广场和已打开知识库标题旁展示已保存的封面。
- 上传成功后由服务端异步启动 RAGFlow 解析；桌面页面不提供手动重新切片。单击打开预览；右击选中并展示移动、复制和删除。移动与复制只能选择个人或共享知识库，并由 OneAPI 同步（先下载再上传，移动时再调用 RAGFlow 删除源文件）。删除会调用 RAGFlow 文档删除接口。图片使用原文件 blob；PDF 用 pdf.js 渲染以便问答引用按 RAGFlow 切块坐标高亮（摘录文本层搜索作兜底）。文件下载走二进制 Fetch，不再经 JSON 字节数组。纯文本使用下载字节；其他类型回退到 RAGFlow 切片文本。回答把 `##i$$` / `#i$` / `[ID:i]` 标注换成对应 RAGFlow `reference` 切块的蓝色序号引用，不会在文末另行添加来源列表。
- 内容菜单可以把本地文件上传到当前知识库。本地文件夹入口暂时隐藏（分页按顶层文件夹或文件计项，整夹上传会挤占分页并拉长单页内容）；网页链接、笔记、腾讯文档、录音纪要、从个人知识库导入会显示，但尚未接入；新建空文件夹入口暂时隐藏。已有相对路径仍按文件夹树展示。
