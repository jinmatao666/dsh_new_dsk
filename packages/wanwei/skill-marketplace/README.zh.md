# @deepseek-ai/dsh-wanwei-skill-marketplace

[English](README.md) | 中文

## 概述

暂存和会话内的技能引用都通过名称按钮打开详情，通过右上角红叉仅移除引用，不卸载技能。打开或关闭详情保留问题草稿。上架技能详情在描述下展示管理员填写的 `usage_example`，保留换行；没有示例时不展示。更新此元数据不需要重新安装技能。

使用技能只暂存可编辑草稿，不创建目录，也不继承上一条会话的工作区。首次发送通过桌面壳创建持久化的时间命名目录。普通工作区索引和会话控制器将工作区显示到侧边栏，并在其中执行技能。启动技能后、发送前手动选择工作区会跳过自动创建。创建失败保留草稿，重试复用已创建的目录。

已安装的平台、个人和 SkillHub 技能详情在“使用技能”旁提供“打开目录”。桌面端在本地技能根目录内解析安装标识，使用操作系统文件管理器打开；未安装技能不显示此操作。此入口不检查 API Key，也不创建或修改配置文件。

选择工作区前，暂存技能名称和可编辑问题处于同一行内排版。名称不按百分比截断；问题紧接名称，后续行使用完整输入宽度。选择工作区后，同一个 slash token 转为普通编辑器引用，不改变发送文字。

万维桌面通过此插件浏览已上架技能、管理本地安装并查看个人上传审核记录。官方 DSH 运行时发现和执行已安装技能。专家工作台、连接器和自动化属于独立插件，不属于本市场。

## 使用本包

万维桌面组合包在官方浏览器 UI 之后挂载此 Client 插件；它不是独立应用。

### 适用情况

桌面需要 OneAPI 提供的目录和本地技能安装时，使用万维产品 profile。官方 DSH 技能包仍负责发现和运行已安装技能。

市场包含仅由平台官方技能组成的推荐区、所有已发布的平台技能以及独立的 SkillHub 区。两个目录分别在紧凑工具栏中管理回车提交的搜索、分类、排序及每页十二张卡片的分页；搜索平台技能时收起推荐区，不筛选 SkillHub。热门排序使用下载量；平台最近更新排序依赖后台时间字段，无时间的条目排在有时间条目后并保持服务端顺序。SkillHub 卡片沿用平台下载图标，不重复显示来源标签，详情以完整页面显示，返回时保留列表位置。我的安装包含本机 SkillHub 记录，支持离线使用、卸载和手动更新。[SkillHub 适配器](../skillhub/README.zh.md) 负责上游请求与限制。

平台技能和 SkillHub 工具栏展示相邻页码、首页和末页，并支持输入有效页码直接跳转。翻页、搜索和筛选保留市场面板的滚动位置。SkillHub 请求下一页时保留旧卡片，避免列表暂时收缩导致面板跳动。

市场面板负责推荐区、目录列表及平台技能详情的纵向滚动。各区保留内容高度，不在共享功能面板的弹性布局中被压缩；其他功能页继续使用各自的内部滚动区域。

推荐卡片使用与平台卡片相同的图标和元信息样式显示已核实的下载量。点击卡片打开详情，卡片不包含安装、卸载或更新控件；技能图标下方的已安装标签保持不变。

平台下载量累计每次成功安装或更新，包括同一账户重新安装。管理员的安装量列对每个技能按账户去重。上报失败会保留本地安装，并明确提示下载量同步失败；不会自动重试。SkillHub 下载量保留上游口径。

目录和我的安装筛选与桌面设置字段共用圆角下拉控件。列表根据可用空间显示在触发框上方或下方，不再使用直角的系统原生弹出菜单。

平台分类选项只来自后台分类管理。客户端不插入固定的“通用”分类；管理员配置的分类仍按实际名称显示。

拖动任一侧栏调宽条会保留当前技能市场面板及其局部状态。点击侧边栏导航操作仍会离开面板；改变布局宽度不会选择对话。

我的安装将平台及本地技能与 SkillHub 安装记录合并为每页十二张卡片的列表。跨来源的同一技能在合并视图中只显示一张卡片，来源筛选仍可分别查看两份安装记录。工具栏包含回车提交的搜索、来源单选框和分页；筛选后回到第一页，卸载后页码随剩余结果收缩。原生技能目录变更会同时刷新平台安装状态和 SkillHub 记录，避免卸载后残留过期的已安装卡片。卡片只打开技能详情，卸载和更新操作放在详情页。此视图读取本地安装记录，不请求上游目录。

### 组合方式

本插件只拥有技能入口、目录、安装、上传和详情。它与 [feature-panels](../feature-panels/README.zh.md) 共用页面外壳和提示；控制器和远程回调属于自己的挂载实例。

个人技能导入弹窗将可见范围与技能来源作为同级表单分组。目录和 ZIP 控件使用一致的紧凑按钮样式；选中路径在下方独占一行，超长时省略并通过悬浮提示展示完整路径。标题栏样式不再作用于来源控件，小窗口下适当收紧间距。

平台和 SkillHub 操作共用简洁的顶部居中提示。SkillHub 进度持续显示到操作结束；安装、更新、卸载在原生操作成功后立即提示，再刷新本地安装记录。刷新失败时明确提示操作已完成，但列表未能刷新。

开始使用已安装技能会暂存其 slash token 和友好名称。输入框在可编辑问题旁显示紧凑的行内技能标签；会话标签序列化为同一 slash token。产品样式留在万维 UI 包中。

产品组合包在[补丁文件](../../bundle/wanwei-desktop/cordis.patch.yml)中持有 `wanwei-skill-marketplace` 配置项。产品安装需要配置 OneAPI Host 和原生桥；本包不要求用户在浏览器输入提供方秘密。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

Client 从产品 Remote 读取已发布的技能目录。安装技能会刷新官方浏览器技能目录。OneAPI 鉴权提供账号范围的 Remote；市场不注册其他业务页面。

SkillHub 返回数据可能包含重复标识。卡片身份包含行位置，换页会移除所有旧行，包括重复条目；每页最多渲染十二张卡片。市场列表与安装列表使用独立身份，切换到本地安装时不保留远端目录卡片。各目录的跳转页码输入框共用紧凑圆角样式。点击卡片立即用列表数据打开详情，再刷新远端字段，不在列表中插入加载提示。安装和更新等待远端字段返回；返回列表后丢弃迟到的响应。

</details>

<a id="model-experience"></a>
## Model Experience

### 技能调用草稿

#### What the model sees

点击“使用技能”只把 `/office-meeting-minutes` 等斜杠标记预置到无会话草稿。只有用户发送提示词后模型才看到这段文本；技能名称的展示不会修改提交内容。

#### Token effect

打开草稿不消耗模型 token。发送后的提示词使用标准 DSH 模型请求及其通常的 token 统计。

#### KV Cache effect

发送前不影响缓存。发送后普通提示词变化可能影响缓存复用。

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- 已发布技能和上传审核记录需要可访问的 OneAPI 服务。
- 两种部署模式下 SkillHub 浏览均依赖上游实际连通性。目录请求失败显示可重试的大幅占位；已安装 SkillHub 技能不依赖目录即可本地使用，技能自身的远程依赖仍可能失败。
