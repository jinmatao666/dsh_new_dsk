# 技能市场客户端

[English](README.md) | 中文

此客户端插件在桌面端通过独立覆盖层展示技能市场、专家库、连接器和自动化。技能市场条目来自服务端目录和本地安装的技能；专家卡片只展示服务端已上架、且当前桌面版本具备工作台的条目。专家团仍为未接入执行流程的展示数据。

已安装技能卡片和详情页提供“使用”入口。点击后打开未选择工作区的新对话页；用户选定工作区后，客户端发送以该技能斜杠名称开头的消息。如果执行还需要任务说明，消息会要求先向用户询问。

“使用”入口会缓存技能中文显示名，供输入框显示紧凑的行内标签；草稿和发送内容仍保留技能的斜杠标识。

地质条件分析专家在专家库内部打开工作台页签。左侧导航包含材料表单、信息核对、个人历史、成果文件和使用说明。表单接受 GeoJSON、Shape ZIP 或选中的 Shape 组件文件，并检查扩展名及 `.shp`／`.shx`／`.dbf` 组合；面几何和坐标参考信息由分析技能检查。页签保持打开时保留草稿，关闭页签或卸载覆盖层后丢弃草稿。

工作台根据归档会话结果区分运行中、已完成和未完成任务。历史页读取各任务状态，支持本机搜索和状态筛选。成果页只列出各任务目录中实际找到的 Word、Excel 路径，提供本机打开文件及文件名、类型筛选；页面不会从模型回答中推断进度百分比、面积、地图或结构化统计数据。

开始分析会先确认本机具备 `market-gis-geology-analysis` 技能，未安装时从已上架技能目录取得并安装。随后在所选工作区建立独立任务目录、导入上传文件，并通过归档的 Host 会话调用技能；归档会话不出现在普通会话列表。工作台展示该会话的实际模型回答，只在任务目录中发现 Word 报告和 Excel 明细时标记完成。个人任务索引按登录用户名保存在本机；跨设备不会同步，删除本机数据或任务目录会导致历史或成果不可用。后台关联技能字段仅供管理查看，不改变此固定执行流程。
