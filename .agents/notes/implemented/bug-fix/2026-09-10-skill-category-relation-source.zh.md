# Agent Note: 技能分类关系的数据来源
[English](2026-09-10-skill-category-relation-source.md) | 中文

Status: implemented

## Problem

分类管理列表此前通过旧的 `skills.category` 展示字符串统计和展开技能，而技能分配使用分类关系 ID。展示字段过期时，同一技能可能同时显示在“通用类”和“空间制图”下。

## Decision

分类管理的数量统计、展开列表和删除校验均以 `skill_category_relations.category_id` 作为技能包分类的权威来源。旧的 `skills.category` 字段继续作为展示和兼容字段，并在技能包分配路径中同步，但不再用于推断后台绑定关系。分类编辑器只保存可编辑的名称和描述，稳定的分类编码和类型保持不变。

## Alternatives considered

**只修复旧展示字段。** 现存数据在迁移完成前可能保留旧值，后续写入也可能再次造成不一致。后台读取必须使用已规范化的关系 ID。

**立即移除旧字段。** 现有技能市场接口和技能包元数据仍公开该字段；移除它会把本次缺陷修复扩大为不兼容的接口变更。

**编辑时写回所有分类列。** 编辑器没有分类编码或类型的输入项。写回这些字段可能触发历史数据库索引冲突，且不会改变管理员实际选择的内容。

## Consequences

每一行分类现在都反映技能市场筛选和下载实际使用的关系。旧展示值不会再产生重复分类行，也不会让技能出现在错误的展开分类中。
