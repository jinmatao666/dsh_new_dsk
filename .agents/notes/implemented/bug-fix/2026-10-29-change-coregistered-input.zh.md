# Agent Note: 接受已配准的变化分析影像

Status: implemented

[English](2026-10-29-change-coregistered-input.md) | 中文

## Problem

用户通常上传已经配准的两期影像。要求特征匹配必须成功，会因为季节或明显地物变化而拒绝正常材料。

## Decision

同尺寸图片在没有可信额外校正时沿用原位置。结果元数据及工作台明确说明此假设，同尺寸本身不能证明地理范围一致。平移校正要求更高相关性并限制移动幅度。几何上不合理的校正对同尺寸材料同样保留原位置，不同尺寸且无法匹配时仍报错。校正后共同范围以外的像素在模型两期输入中设为相同，避免边界假变化。

## Alternatives considered

**匹配失败一律报错**会阻止本来已有正确像素对应关系的已配准材料。

**把所有图片强行拉伸到同尺寸**会引入几何误差，并错误暗示已经配准。

## Consequences

服务可处理常见已配准影像，但不能仅凭尺寸确认地理对应。用户仍须提供同范围图片，实际模型准确性需要服务器推理验收。

## Testing

回归测试覆盖低纹理同尺寸输入、不同尺寸无法匹配时拒绝以及已知平移恢复。用户提供的11对真实影像均通过对齐及输入处理，不代表已测得变化识别准确率。
