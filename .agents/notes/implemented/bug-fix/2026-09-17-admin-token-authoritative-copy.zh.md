# Agent Note: 管理员复制令牌时读取权威密钥

Status: implemented

[English](2026-09-17-admin-token-authoritative-copy.md) | 中文

## Problem

后台用户详情页为每个模型访问令牌提供复制操作。列表行属于展示数据，可能过期、缺失或经过脱敏，因此直接复制其中的 `key` 可能提示成功，却没有把当前可用的真实密钥写入剪贴板。

## Decision

管理员令牌接口提供同时受用户 ID 和令牌 ID 限制的已认证查询。复制操作在写入剪贴板前即时请求该记录，并为返回的密钥添加 `sk-` 前缀。记录不存在或剪贴板写入失败时，界面显示明确错误；剪贴板操作完成前不会提示成功。

## Alternatives considered

**复制令牌列表携带的密钥** — 不采用，因为列表响应服务于表格展示，不能保证操作发生时其中的密钥仍然完整且有效。

**为管理员提供不受用户限制的单令牌查询** — 不采用，因为同时绑定当前用户可以避免令牌 ID 返回其他用户行之外的密钥。

## Consequences

复制会增加一次已认证请求，并且只向本就能够管理该用户令牌的管理员返回完整密钥。列表继续负责名称、额度、状态和期限展示，不再充当凭据复制的数据源。
