# Agent Note: 文件交付保留正文答案

Status: implemented

[English](2026-10-15-file-delivery-preserves-answer.md) | 中文

## 问题

提示词生成任务运行本地脚本后完成了文字答案。最终文件插件把终端执行推断为文件产出，在轮次结束时 steer 了另一次请求。模型声明空文件清单并返回确认摘要，完整答案被对话归入过程折叠区。

## 决策

文件交付插件登记经过校验、替换式的文件清单，不注册轮次结束监听器。模型收到在最终答案之前完成登记并保留用户所需文字结果的指引。空清单仍然有效，只影响文件交付。终端执行不是最终文件存在的证据。通用对话答案投影不变；本修复阻止插件仅为文件登记创建更晚的答案。

## 考虑过的替代方案

**保留更强的结束提醒。** 无论如何措辞，在答案完成后提醒仍会创建另一次模型请求，把已完成的答案变成中间消息。

**在官方聊天投影里特殊识别私有交付工具。** 这把通用答案选择与私有工具耦合，还可能隐藏后续实质性回复。因此由发起插件移除强制续跑。

## 影响

文件保留存在性校验、身份去重、失败处理和空清单清空能力。模型漏报文件时，不在答案完成后强制重试；文件声明准确性仍需安装版桌面端验收。Loader 组合回归覆盖空清单和非空清单、无效文件、终端或文件操作后不 steer、提示词文本与卸载。已有日志不重写。
