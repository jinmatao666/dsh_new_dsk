# Agent Note: 桌面端技能发现范围

Status: implemented

[English](2026-10-16-desktop-skill-discovery-scope.md) | 中文

## 问题

桌面端继承了通用技能发现行为：共享 `~/.agents/skills` 和最近的上层 Git 仓库可能把无关技能混入所选工作区。

## 决策

文件系统提供方新增 `projectRootMode` 和 `includeUserAgentsRoot`，通用默认值仍为 `git`、`true`。万维桌面产品层使用 `cwd`、`false`。保留桌面端安装技能和显式配置的自定义或内置根目录。不删除或迁移技能。

## 考虑过的替代方案

修改全局默认值会影响官方 CLI 和其他使用方。关闭全部默认根目录又会丢失桌面端安装技能和工作区内技能。这些都不是本次产品策略所需。

## 影响

回归测试覆盖准确工作区发现、切换工作区、无 cwd 查询、共享同名冲突、排除上层目录、安装技能和显式自定义根。Loader 组合测试读取桌面端交付配置并核对实际目录。这是发现范围，不是文件系统沙箱：显式配置根和原有软链接支持仍保留。Windows 下两项已有软链接测试需要当前开发终端不具备的权限；未屏蔽其 EPERM 失败。
