# Agent Note: 文件夹剪贴板导入

Status: implemented

[English](2026-10-15-folder-clipboard-import.md) | 中文

## 问题

剪贴板目录可能表现为浏览器 File 对象。读取其字节可能在原生目录导入器运行前抛出 NotFoundError。

## 决策

文档粘贴优先查询原生剪贴板文件列表，通过有容量限制的工作区路径导入器处理文件和目录。仅当原生列表为空时才允许浏览器字节导入。图片和文字保持原有处理。

## 考虑过的替代方案

WebView 不提供目录条目时，浏览器条目检测不足以识别目录。对所有原生错误重试浏览器字节可能重复部分完成的导入，因此原生错误直接显示，不执行该重试。文件选择与拖入行为不变。

## 影响

文件夹粘贴不读取浏览器字节，保留原生容量限制与同名处理。每次文档粘贴会先读取原生剪贴板，再按需执行浏览器字节导入。

## 测试

客户端回归覆盖不可读取的目录 File、每次粘贴仅导入一次、原生列表为空时的字节导入、图片文字混合粘贴及错误显示。Windows 和 macOS 安装版的系统剪贴板行为仍需发布验收。
