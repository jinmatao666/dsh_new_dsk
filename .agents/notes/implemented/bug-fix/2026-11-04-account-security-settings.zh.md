# Agent Note: 桌面账户安全设置

Status: implemented

[English](2026-11-04-account-security-settings.md) | 中文

## Problem

账户设置原来展示模型列表，没有提供新注册用户所需的手机号、密码和微信管理。

## Decision

替换为三行设置及弹窗验证表单，关闭时恢复焦点并清空草稿，保留账号信息和退出登录。通过固定Host白名单复用已有服务端接口，不向浏览器传递凭据及完整用户资料。密码修改、微信绑定解绑验证已绑定手机，换手机号分别验证旧号和新号。不从旧系统生成密码推断用户是否主动设过密码。

## Alternatives considered

模型列表不能管理登录身份；非空密码哈希不代表用户主动设置；跳转外部账号页需要额外认证交接。

## Consequences

不需要数据库变更。账户弹窗收紧为420px并移除图形验证码；新增已认证绑定短信接口，已有密码、换号短信接口保留登录校验和短信限流，公开图形验证码策略不变。本次需同时更新后台与桌面端。真实短信及微信授权依赖服务端配置和网络。微信二维码接口对已绑定身份另行返回状态，绑定扫码不会切换桌面当前账号。本页不实现公开注册或登录页短信、扫码入口。

## Testing

十项专项测试覆盖退出登录、移除模型、密码提交、双验证码换绑、读取失败、资料脱敏、操作白名单及二维码来源限制。另外两项控制器测试验证登录校验、公开图形验证保留及已认证短信限流。类型检查和专项lint通过。浏览器替身渲染实际组件与CSS，检查宽窄窗口；没有调用真实短信和微信授权。
