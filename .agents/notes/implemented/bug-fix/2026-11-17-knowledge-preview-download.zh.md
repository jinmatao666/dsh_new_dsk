# Agent Note: 知识库预览下载使用原生保存

Status: implemented

[English](2026-11-17-knowledge-preview-download.md) | 中文

## 问题

文件预览在下载点击事件结束前撤销了 blob URL。浏览器可能在事件结束后才解析 URL，桌面 WebView 也无法可靠地通过链接下载保存文件。

## 决策

桌面主窗口将已授权的文件字节和原始文件名交给原生下载功能。原生功能将文件保存到「下载」文件夹，遇到同名文件时使用新名称。本地保存失败时，当前预览保留已付费的文件字节以供重试。浏览器发起下载后会暂时保留 blob URL。

## 后果

桌面端仅在文件写入完成后显示保存结果。下载文件保留原始扩展名，包括预览标题省略扩展名的格式。

## 考虑过的方案

延长浏览器链接的有效期可解决浏览器中的 URL 时序问题。原生命令还能报告桌面端文件写入成功或失败。
