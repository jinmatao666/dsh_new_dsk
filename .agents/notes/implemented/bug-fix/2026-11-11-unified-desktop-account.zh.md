# Agent Note：桌面端统一账号身份

Status: implemented

[English](2026-11-11-unified-desktop-account.md) | 中文

## 问题

短信登录可能显示业务库占位名，而账户设置显示账号中心用户名；修改名称也可能改变模型偏好的归属。

## 决策

用户名、手机号密码、短信验证码和已绑定微信登录均对应同一个账户。绑定时保留已有用户名；只有缺少用户名时，才用本账户已验证的手机号初始化，并使用与标识写入共享的账号行锁。微信轮询读取账号中心的最新身份信息，在桌面端建立正式会话前要求验证并绑定手机号，不用微信昵称生成用户名。登录和账户设置均返回真实用户名；读取账户信息和改名后同步桌面端共享状态及本地凭据，退出后的迟到响应不能恢复原账号。

用户名允许 2–32 位中文、字母、数字或下划线，且保持唯一；手机号形式的用户名必须是本账户验证过的号码。模型偏好按后台地址和稳定的产品用户 ID 保存，并为当前已验证账户迁移原有用户名键。

## 考虑过的替代方案

每次登录覆盖用户名会让切换登录方式变成改名；按可修改的用户名识别账户会拆散模型偏好。绑定冲突时自动合并账号则可能转移不同所有者的数据。

## 影响

无需修改数据库结构，桌面端和后台需要一起更新。积分、权限和用户 ID 仍归属原账户。本地身份同步不实现跨设备会话同步。真实微信授权和短信发送仍依赖服务商配置，专项测试使用模拟服务和本地数据库。
