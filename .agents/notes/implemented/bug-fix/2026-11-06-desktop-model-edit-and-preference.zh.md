# Agent Note: 桌面端模型编辑和最近使用模型

Status: implemented

[English](2026-11-06-desktop-model-edit-and-preference.md) | 中文

## Problem

旧编辑器绕过了新增表单的测试，刷新官方模型目录时也可能覆盖用户上次交互使用的模型。

## Decision

桌面端编辑自定义模型时复用新增表单和连接测试。当前表单通过测试后才能保存，保存写回原有模型路由。后台只会向原地址复用已存的 API 密钥。更换地址并输入新密钥时，先存储新密钥，再切换路由。

在输入框里选模型只会改变当前会话。桌面端接受一条交互消息后，会记住该消息使用的模型，作为以后会话的默认选项。连接器和定时任务不会开启此行为。桌面端刷新官方模型列表时保留仍可用的选择，并在同一安装环境中恢复各账号的选择。如果该模型已不可用，则在当前后台有可用模型时回退到后台目录。

## Alternatives considered

**选择时保存。** 未使用的选项或自动化任务可能改变新对话的默认值。交互消息被接受后再记录选择。

## Consequences

偏好保存在本机，按后台和登录账号区分。已有会话继续使用自己的模型。
