# Agent Note: 专家管理字段报错与搜索样式统一

Status: implemented

[English](2026-10-30-expert-admin-validation.md) | 中文

## Problem

专家搜索框使用默认灰底，与技能管理不一致；新增和编辑将提供方缺失、图片过大等校验问题合并为笼统报错。

## Decision

使用专家页作用域样式复用技能搜索的白底、尺寸、边框与聚焦效果。提交前校验常用字段，新增和编辑接口返回具体校验信息。名称、提供方、简介、底部说明、图标、标签及介绍区块分别报错；重复编号与数据库保存失败分开提示，不暴露SQL信息。

## Alternatives considered

笼统提示要求用户猜测；仅前端校验无法覆盖直接API调用及旧客户端。

## Consequences

校验限制保持原样，介绍区块正文允许留空。每次提示首个无效字段；并发插入重复编号仍可能收到通用保存失败。不需要数据库迁移。

## Testing

控制器测试覆盖新增、编辑各类字段错误响应、重复编号和数据库检查失败。Windows缺少C编译器，数据库测试使用临时Go overlay切换已有纯Go SQLite驱动通过，不修改生产代码或已提交的测试驱动导入；前端测试覆盖表单校验及原编辑行为。搜索选择器沿用已有技能搜索规则，上线需要重新构建后台镜像。
