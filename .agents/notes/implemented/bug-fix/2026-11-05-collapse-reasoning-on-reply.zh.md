# Agent Note: 收起思考并保持正文可见

Status: implemented

[English](2026-11-05-collapse-reasoning-on-reply.md) | 中文

## Problem

思考展开状态没有在首个正文增量出现时重置。整轮折叠在轮次结束后才有可靠答案边界，若对运行中的轮次提前套用该边界，会误藏正文。

## Decision

正文始终独立渲染。无正文时流式思考展开；出现正文后切换为默认收起阶段，随后手动展开不会随正文增量重复收起。已完成思考默认收起。Chat挂载或会话切换清空过程展开记录，会话键控制节点本地状态重置。已完成轮次边界和历史分页保护保持原样。

## Alternatives considered

对运行中轮次直接执行整轮折叠，可能把过程叙述或稍后的答案误当作思考。

## Consequences

流式阶段仅自动折叠思考，工具和过程折叠等待已确认的完成答案。恢复视图会清除之前的手动展开状态。
