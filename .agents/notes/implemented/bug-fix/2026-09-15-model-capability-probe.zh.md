# Agent Note：模型能力检测

状态：已实施

[English](2026-09-15-model-capability-probe.md) | 中文

## 问题

管理后台的模型页面只使用一张固定红色图片检测图片输入能力，并接受任何包含 `red` 的回答。纯文本模型即使忽略图片，也可能猜中颜色，随后持续作为支持图片的模型下发给桌面端。后续无法得出结论的检测也会保留这个错误结果。

## 决策

能力检测向每个已启用的来源渠道发送三张预期颜色不同的纯色图片。去除回答两侧无意义的标点后，每次回答都必须与要求的颜色单词完全一致。只有所有已启用来源都通过全部检测，模型才会保存为多模态模型。

接口明确拒绝图片输入或模型识别错颜色时，将模型保存为文本模型。传输和渠道故障无法证明模型能力，因此接口返回错误并保留原结果。管理后台列表只把保存结果展示为“文本模型”或“多模态模型”，不再在模型名称下方和编辑表单中重复展示能力。

## 考虑过的替代方案

**保留一张固定图片，只收紧回答匹配。** 精确匹配可以拒绝带解释的臆测回答，但纯文本模型仍可能猜中一个固定颜色。

**根据模型名称推断能力。** 供应商别名和私有部署使名称规则不完整，不能安全地用于桌面端图片准入。

## 结果

图片能力采用保守判断，并在模型可能使用的所有来源上保持一致。每个已启用来源的一次检测会产生三个小请求。发生临时渠道故障后，管理员需要重试，因为无法得出结论的检测不会覆盖已保存能力。
