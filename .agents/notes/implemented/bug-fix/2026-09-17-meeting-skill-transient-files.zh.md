# Agent Note: 在可写输出目录中存放会议技能临时文件

[English](2026-09-17-meeting-skill-transient-files.md) | 中文

Status: implemented

## Problem

会议纪要技能会在指定输出目录下创建临时子目录。桌面端工作区权限虽然允许写入输出目录，但可能拒绝 FFmpeg 写入工具进程启动后创建的子目录，导致 ASR 服务可用时，技能的标准入口仍在转写前失败。该流程还会把内部 Markdown 汇总和处理报告显示为用户产物。

## Decision

音频标准化和分段改为直接在指定输出目录中使用唯一的临时文件，并在转写结束后删除。会议整理所需的 Markdown 输入也是临时文件。音频任务只返回转写文本和最终 Word，文字材料任务只返回最终 Word；技能不返回 Markdown、JSON、内部材料汇总或处理报告。

## Alternatives considered

**申请更大的桌面端权限。** 未采用，因为技能只需写入用户选择的输出目录，不应仅为内部文件再申请一次权限。

**使用操作系统临时目录。** 未采用，因为桌面端沙箱不保证技能可以写入所选工作区以外的位置。

**保留中间文件用于诊断。** 未采用，因为政府办公用户需要的是请求的文档，内部 Markdown 和 JSON 只会增加产物干扰，并不是诊断 API 请求失败的必要条件。

## Consequences

处理期间，输出目录中可能短暂出现具有唯一名称的 WAV 或 Markdown 文件；无论执行成功还是失败，技能都会尝试删除这些文件。音频任务显示 TXT 转写稿和 Word 会议纪要，纯文字任务只显示 Word 会议纪要。运行时测试在不调用真实模型的情况下验证产物类型和临时文件清理。
