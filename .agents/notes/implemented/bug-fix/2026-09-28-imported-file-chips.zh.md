# Agent Note: 导入文件标签

Status: implemented

[English](2026-09-28-imported-file-chips.md) | 中文

## 问题

桌面导入用路径文字替换输入框草稿。带引号的文件名可能显示成原始引用，异步导入完成也可能覆盖新输入的文字或已有引用标签。

## 决策

通用会话动作 `appendReferences` 向实时编辑器追加结构化引用。产品插件负责文件名标签、路径引用、原生命令及拖入监听。文件和目录引用复用已有引用编解码器和标签组件。

桌面将窗口级和主 WebView 级拖放事件转发到可信渲染页面。Tauri 的 `unstable` 多 WebView 运行时把主视图创建为子视图，其拖放通过 `WebviewEvent` 投递，而不是 `WindowEvent`。

## 考虑过的替代方案

**用引用文字替换整个草稿。** 这会丢失结构化引用，显示也依赖自动识别文字中的引用。

**把桌面导入放进官方编辑器。** 这会把产品命令耦合进官方 UI 代码。编辑器仅接受通用引用数据。

## 影响

导入保留现有内容和模型路径引用。输入动作实现需要提供新增回调。浏览器文件 dragover 放行投递；原生外壳拖入仍需桌面验证。

## 验证

输入框和产品测试覆盖连续导入、带引号路径、目录、实时草稿、锁定会话、原生投递事件及提交路径序列化。这些测试不代表已验证安装版桌面拖入。
