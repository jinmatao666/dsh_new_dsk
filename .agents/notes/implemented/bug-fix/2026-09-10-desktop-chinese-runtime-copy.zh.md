# Agent Note: 桌面端运行时中文文案
[English](2026-09-10-desktop-chinese-runtime-copy.md) | 中文

Status: implemented

## Problem

即使桌面端面向中文用户配置，模型生成的工具摘要、审批理由和提问内容仍可能以英文到达界面。

## Decision

桌面端配置文件要求模型对所有面向用户的自然语言使用简体中文。客户端保留模型给出的中文内容，并将非中文的工具摘要、审批理由、提问标题、提问说明和选项文案替换为本地化中文兜底文本。命令、路径、包名、标识符和原始错误文本保持原样。

## Alternatives considered

**在客户端翻译任意文本。** 客户端没有可靠的翻译服务；隐式远程翻译调用会为每次会话更新带来延迟、隐私暴露和新的失败方式。

**只依赖系统提示。** 模型仍可能输出不符合要求的文本，因此展示组件为简短的流程文案提供确定性的兜底。

## Consequences

即使模型产生英文元数据，用户仍会看到中文流程控件。短流程文案中不再展示精确的英文措辞；原始命令和其他技术材料仍可供查看。
