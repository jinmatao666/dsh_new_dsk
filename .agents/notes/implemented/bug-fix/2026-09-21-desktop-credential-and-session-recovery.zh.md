# Agent Note: 桌面凭据与会话恢复

Status: implemented

[English](2026-09-21-desktop-credential-and-session-recovery.md) | 中文

## Problem

已安装的桌面版可能遇到另一版本写出的 `version: 1`、`refs`、`records` 包装格式凭据文档。扁平格式凭据提供方会把 `version` 当作非字符串凭据而拒绝，导致退出登录及其他凭据写入失败。搜索请求事件若未进入生成的已知事件目录，也会令其他内容有效的对话历史无法读取。

## Decision

凭据提供方只识别这一准确的旧版包装格式，先将原文档复制为相邻的唯一备份，再将 `refs` 中的条目原子写成扁平格式。启动时迁移在写锁下重新读取文档；凭据写入在同一把锁下发现旧格式时也会迁移。其他无效文档仍然报错。

OneAPI 搜索请求进入生成的持久化目录。新事件带有 `ignorable: true`：不认识此观察事件的读取器可以跳过它而不丢失对话状态。当前读取器按类型识别此前未标记的实例。

桌面输入框在 WebView 未提供 `Files` 拖入类型但文件列表非空时接收浏览器拖入，并合并同一次拖入的浏览器和原生通知。

## Alternatives considered

**接受任意包装格式或未知凭据字段。** 这可能静默丢弃凭据或误解无关数据，因此拒绝。

**跳过所有未知会话事件。** 未知的必需事件可能改变对话重建结果，因此拒绝。

## Consequences

升级保留凭据及原文档备份；旧版写入者再次恢复包装格式后，退出登录仍可移除令牌。包含该搜索事件的现有历史可以在更新事件目录后的版本加载。旧版读取器仅能跳过带可忽略标记的新搜索记录；对其不认识且未标记的旧记录仍会拒绝。
