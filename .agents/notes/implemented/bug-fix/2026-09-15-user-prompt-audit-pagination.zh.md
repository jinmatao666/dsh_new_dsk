# Agent Note: 用户提问审计分页

Status: implemented

[English](2026-09-15-user-prompt-audit-pagination.md) | 中文

## Problem

模型日志页面只加载固定的一批用户提问审计记录，管理员无法查看更早的内容。在数据库偏移之后再过滤框架生成的消息，也可能导致分页之间出现重复或遗漏。

## Decision

管理员接口先应用共用的框架消息排除规则，再进行计数和分页，并随请求页返回过滤后的总数。模型日志页面每页请求 50 条记录，根据总数提供页码、上一页和下一页导航。

写入路径和列表路径共用同一份排除前缀列表，使框架消息既不会进入新记录，也不会出现在历史查询结果中。列表加载器会丢弃已被较新页码请求取代的响应。

## Alternatives considered

**在浏览器中对首次响应分页。** 前端分页无法展示服务器没有返回的记录。

**只提供上一页和下一页。** `has-more` 响应可以支持顺序浏览，但无法展示匹配记录总数，也不能直接选择页码。

## Consequences

管理员可以按稳定的每页 50 条浏览完整的过滤后审计历史。为了让界面展示总数和页码，每次分页请求还会执行一次带过滤条件的计数查询。
