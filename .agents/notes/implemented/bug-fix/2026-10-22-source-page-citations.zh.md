# Agent Note: 网页引用使用检索返回的原网页

Status: implemented

[English](2026-10-22-source-page-citations.md) | 中文

## 问题

即使结构化检索元数据包含真实 URL，搜索模型摘要仍可能包含虚构结论和链接。将摘要传给对话模型，可能导致模型重复无依据的新闻并附上无关引用。泛称引用标签无法标识实际引用的网页。

## 决策

OneAPI 搜索提供方转发结构化检索 URL，但不转发生成的摘要正文。接受检索元数据时不要求存在生成答案；没有来源时返回核验警告，而不是无来源摘要。认证后的搜索请求要求提供具体支撑网页，并使用真实标题作为可点击的链接文字。

产品持有的系统提示词段要求通过可用的网页读取或浏览器工具读取候选页面，核对结论依据及日期，并使用检索或实际读取页面的真实标题引用实际返回的网址。没有真实标题时显示可点击的原文 URL，不编造标题，也不用泛称标签代替。读取失败或缺乏支持的结论必须标记为未核实或省略。该指令独立于不可信网页内容，归 Host 提示词所有，注册随插件卸载清理。标准、PTC 和 Cordis 预设已提供 web_fetch；本次不修改其工具配置。

多条新闻请求中，每条新闻都需要不同的原文 URL 支撑；一篇热点汇总只能算一个来源。提供方报告不同检索链接的数量，只有一个来源时明确警告。搜索请求要求尽量寻找不同发布网站的独立原文。继续搜索后仍缺少足够的核实来源，就减少条目，而不是将汇总页拆成虚假的独立引用。

查询词保持原样，检索要求通过独立消息传递。保留上游实际返回的结构化摘要和有效ISO发布日期，不采用生成式回答作为原文。先读取相关文章，再针对缺项补搜；来源多样性是质量目标，不设三个网站的答复门槛。连续补搜没有新增有效来源时应停止，并指出失败环节。单个正向site条件按实际返回域名校验；全部不匹配时返回WEB_PROVIDER_SCOPE_MISMATCH，不据此断言该网站没有新闻。复合OR查询保持原样。这些指引不构成最终回答的程序化校验，也不证明真实搜索已经查全。

## 考虑过的替代方案

**只改标签。** 统一标签不能阻止虚构链接和无依据结论进入模型上下文。

**从生成正文解析链接。** 语法正确的链接不代表检索证据。使用结构化元数据无需依赖每种 Markdown 或 HTML 链接写法。

## 影响

桌面端带新窗口目标的 HTTP(S) 来源链接直接调用仅主窗口可用的 `open_external_link` 命令。原生命令先检查与 WebView 新窗口回调相同的网络策略，再打开系统浏览器。点击会取消 WebView 导航，避免重复开窗；右键、本地文件链接、下载和普通浏览器使用保留原有处理。原生打开失败时显示提示，避免点击后没有反馈。内网模式的外部链接限制仍生效；服务器资源中转不为系统浏览器提供代理。

核对来源可能增加耗时及 token。过滤生成摘要可以确定性地移除这条上游虚构正文与 URL 的输入路径；但不证明检索 URL 可访问，也不保证最终对话模型遵循引用指令。不承诺实时新闻真实性。定向测试覆盖有无结构化来源时的虚构链接、缺少摘要、URL 过滤，以及经 Loader 挂载的提示词和工具展示快照。
