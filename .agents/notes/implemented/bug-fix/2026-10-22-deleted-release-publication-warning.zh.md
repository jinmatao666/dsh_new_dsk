# Agent Note: 已删除发布版本不触发发布警告

Status: implemented

[English](2026-10-22-deleted-release-publication-warning.md) | 中文

## 问题

删除平台历史最高版本的上传记录后，通道仍保留其版本号。仅与该值比较发布版本，会向管理员提示已经删除的版本。

## 决策

发布时先检查同一平台是否仍存在通道历史版本对应的上传记录，再决定是否要求低版本确认。缺失的上传记录不参与比较，检查上线前遗留的通道也适用，无需数据库迁移或再次删除。这替代了[发布删除决策](../feature/2026-10-21-desktop-release-deletion.zh.md)中针对已删除上传记录的警告行为，不改变撤下、签名或客户端版本比较。

## 考虑过的替代方案

**只在删除时清空历史值。** 之前已删除的上传记录仍会触发警告，直到手动修复。

**只在浏览器隐藏警告。** 发布接口仍会拒绝请求并返回确认响应。

## 影响

历史上传记录仍存在时，发布更低版本依然要求明确确认。删除上传记录不代表允许已安装客户端降级：相同或更高版本的客户端仍不获得更新。集成测试覆盖删除后发布、遗留孤立通道历史、精确平台隔离及客户端版本比较。
