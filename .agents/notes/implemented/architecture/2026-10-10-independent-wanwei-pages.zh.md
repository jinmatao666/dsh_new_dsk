# Agent Note: 独立万维功能插件

Status: implemented

[English](2026-10-10-independent-wanwei-pages.md) | 中文

## 问题

一个技能市场挂载注册四个无关业务页面。停用市场因此也会移除专家、连接器和自动化，模块级回调还可能保留其他挂载实例的状态。

## 决策

产品组合四个独立业务包：skill-marketplace、expert-library、connectors 和 automations。各包只注册自身侧边栏入口和页面，拥有自身状态和回调，可通过自身 Cordis 配置项独立停用。共用鉴权和模型执行仍由现有提供方包负责。

共用 feature-panels 模块拥有展示辅助函数，不注册业务。调用方在 dsh.client.external 声明其 Client 导出，并保持提供方配置项挂载。打开页面广播浏览器本地导航事件；其他独立控制器收到事件时各自关闭。Context 卸载关闭页面、清空订阅并移除事件监听。退出登录关闭全部活动页面。调宽和所属下拉不改变导航。

专家工作台保留原生标签生命周期和票据校验。纯内网禁用专家；市场保留平台及本地技能，禁用 SkillHub。[分环境功能设置](../feature/2026-10-10-environment-feature-visibility.zh.md)分别控制连接器和自动化入口显示。连接器和自动化交互仍是演示，不提供真实集成或调度。

## 考虑过的替代方案

**在一个插件中保留四个控制器：** 独立 UI 状态无法提供独立插件启停和卸载，因此仍保留归属问题。

**把页面外壳复制到每个插件：** 这样可移除共用 UI 依赖，却会重复导航修复和视觉规则。仅展示模块保留复用，不引入业务之间的依赖。

## 影响

产品组合、工作区导出和类型引用显式包含新包。官方页面外壳行为不变。共用展示是额外的提供方依赖，但任何业务插件都不依赖另一个业务插件。

控制器测试覆盖独立实例、切换、卸载、退出登录、订阅错误和网络策略展示。产品 profile 浏览器回归验证四个入口和调宽。UOS、macOS、Windows 原生专家 Webview 验收仍是单独的平台检查；jsdom 和浏览器测试不宣称覆盖原生执行。
