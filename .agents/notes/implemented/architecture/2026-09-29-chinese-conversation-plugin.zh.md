# Agent Note: 可撤销的中文对话适配

Status: implemented

[English](2026-09-29-chinese-conversation-plugin.md) | 中文

## 问题

桌面端需要中文优先的沟通和交互标签，同时不能将产品翻译耦合到官方包，也不能改写持久化对话中的原始记录。

## 决策

产品组合包加载独立的[中文插件](../../../../packages/wanwei/chinese/README.zh.md)。它注册提示词段落和可选语言，并回退到官方中文。官方权限、命令菜单和推理等级视图只将交互标签交给现有语言翻译函数。缺少翻译时返回原文，保持无插件时的应用行为。新增中文文案和语言选择的释放逻辑均由插件拥有。

默认策略覆盖过程沟通和最终回答：候选文件确认、澄清问题及选项、环境就绪说明均使用简体中文。技能说明、文件内容和历史记录中的英文不代表用户的语言要求。语言段落位于官方工具说明之后、结构化输出指令之前，同时保留用户明确的语言要求、原始文件名、路径、工具结果和机器值。

## 考虑过的替代方案

**DOM 替换：**依赖页面结构，可能覆盖对话内容或与 React 更新冲突，因此未采用。运行时词典参与现有语言修订通知。

**替换专家提示词或翻译工具结果：**会改变专家指令和模型可见的原始记录，因此未采用。追加提示词段落保留二者，并遵循完整提示词模式的排除规则。

## 影响

产品默认选择中文语言包。停用其 Loader 项会移除两端贡献；除非用户已经切换语言，否则恢复此前的语言。机器值和菜单执行路径不变。精确匹配使未知描述保持原文；完整提示词模式保留官方隔离。移除插件后，历史中文回答仍然保持中文。

## 测试

宿主测试固定策略文字，验证专家提示词保留、完整提示词隔离及资源释放。客户端测试验证官方回退、交互标签翻译、未知文字回退和语言恢复。产品 profile 冒烟测试检查桌面端在插件启用和停用时均能加载。现有权限、命令和模型选择器测试验证执行行为不变。

宿主测试还固定段落顺序，并验证部署显式指令的保留。这些检查验证提示词装配，而非真实模型的遵循程度；策略不改写历史回答，也不保证每次模型输出的语言。
