# Agent Note: Explicit cache channel policy

Status: implemented

[English](2026-11-03-explicit-cache-channel-policy.md) | 中文

## Problem

模型编辑允许向缓存协议未知的自建接口注入缓存标记。“启用模型”复选框与列表操作重复。

## Decision

编辑器提供显式缓存下拉框并保留模型启用状态。渠道元数据提供可选状态而不提供凭据。当前策略仅开放已适配的百炼官方接口协议；自定义兼容、自建和尚未适配的接口保持关闭。更换来源时，不允许的渠道关闭缓存，允许的渠道默认开启。重新打开时保留允许渠道已保存的关闭状态。

转发在注入缓存标记前检查实际渠道，历史记录即使开启缓存也受约束。该策略属于适配范围限制，不是实际能力探测，也不控制隐式缓存计费。

## Alternatives considered

**仅禁用界面。** 历史设置仍可能向自建渠道注入不支持的缓存标记，因此不采用。

## Consequences

管理员可调整允许渠道的下拉框，模型启停由列表操作管理。未知接口须完成协议适配后才能开放。逐模型实际检测仍为独立能力。
