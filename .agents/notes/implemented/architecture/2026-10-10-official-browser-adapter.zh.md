# Agent Note: 万维运行时接入官方浏览器提供方

Status: implemented

[English](2026-10-10-official-browser-adapter.md) | 中文

## 问题

官方浏览器提供方要求等待 Agent 创建完成，并依赖工作目录服务。此桌面运行时同步发送创建事件，并在会话头中记录工作区目录。直接安装可能与首次模型请求竞争，也无法解析必需的目录服务。

## 决策

独立浏览器插件挂载未经修改的 `0.2.1-alpha.2` 官方 npm 提供方。仅提供方使用的 Context 提供经过验证的会话目录与初始化信号。提示词组装等待注册完成，并重新收集工具目录。取消一轮问答只停止该轮等待，不转移会话浏览器的所有权；释放会取消并等待启动任务。插件拥有的设置卡片保存 `wanwei-browser-use.enabled`，默认启用；`DSH_BROWSER_USE_ENABLED=0` 设置组装层默认值，可通过 `DSH_BROWSER_EXECUTABLE` 指定可执行文件。停用隐藏工具定义并拦截后续调用，不终止正在运行的操作。停用或纯内网会话将初始化推迟到允许使用的提示词组装；已保存权限在重启后保留，不被网络模式覆盖。

产品优先解析显式可执行文件路径，否则检查标准 Chrome/Edge 安装目录（Linux 还在 PATH 中检查 Chromium），将选定路径传给未经修改的提供方。无效显式路径使配置失败；自动识别无结果时，浏览器调用被拒绝并返回中文说明。可识别的启动失败在中文工具处理说明后保留上游诊断。记录到提示词的指引禁止模型自行安装浏览器或改用 Shell/CDP 绕路，并要求验证码交给用户处理；这不是 Shell 层面的强制限制。解析器不下载浏览器，改变选择需要重启并新建会话。

## 考虑的替代方案

**升级整个运行时。** 这会改变无关的产品生命周期和包 API；当前浏览器需求不足以支持该范围。

**修改官方浏览器源码。** 复制分支会使每次上游更新变成合并工作。仅提供方使用的适配器保持发布代码不变。

## 影响

共享 Agent 注册表和循环保持不变。固定发布包需要针对本地服务进行有限的 peer 版本接受和集成测试。在具备浏览器网络约束之前，纯内网模式拒绝所有浏览器工具；仅检查 URL 无法限制重定向和子资源。本包不下载 Chromium。已安装桌面端的模型驱动验证和平台打包验证尚未完成。卡片使用现有设置插槽和语言服务，没有复制修改官方设置组件。

## 验证

桌面生产部署根依赖万维产品包，由 pnpm 暂存固定版本浏览器包及其传递 npm 依赖。仅恢复 workspace 文件不会补齐注册表包。打包后的 profile 启动检查使用随包 Node，不使用 workspace 解析锚点。

定向测试覆盖启动就绪、工具目录重新收集、取消等待、启动失败、延迟初始化、持久化权限和内网直接调用拒绝。卡片测试覆盖停用写入、内网状态与保存失败。真实 Loader 组合启动固定版本 MCP 与已安装 Chromium，停用时拒绝导航，重新启用后导航到 `about:blank`，验证文件持久化并检查作用域清理。这是工具执行器验证，不是付费模型驱动问答。

可执行文件解析测试覆盖标准目录顺序、Edge 回退、浏览器不存在和显式路径。反馈测试固定中文启动失败结果并检查策略销毁。Windows 上的真实 Loader 测试不指定可执行文件路径，以可见窗口启动 Chrome，在离线测试页面上完成导航、表单输入、按钮点击和结果回读。本次 Windows 浏览器运行不证明 macOS/Linux 自动识别已通过实机验证。
