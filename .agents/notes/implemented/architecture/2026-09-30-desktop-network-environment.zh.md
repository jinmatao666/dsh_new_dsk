# Agent Note: 桌面网络环境

Status: implemented

[English](2026-09-30-desktop-network-environment.md) | 中文

## 问题

纯内网部署需要内部登录与模型访问，但不能把公网 SkillHub、专家、连接器和搜索展示为可用。仅用于视觉的选择无法落实限制，也无法在应用重启后保留。

## 决策

认证 Host 持有持久化的 `wanwei-network.mode`，默认使用互联网。Client Slot 钩子共用可观察的状态镜像，并把已提交策略同步到原生 URL 打开。管理员配置的登录与模型地址不被改写。

SkillHub RPC 在上游 I/O 前被拒绝。已安装 SkillHub 定义通过安装凭据过滤，包含缓存读取。官方工具与技能注册表只增加通用可用性与过滤注册。公网搜索从所有作用域移除；公网网页读取在执行前被拒绝。专家和连接器入口置灰；Host 独立拒绝专家 RPC。本地卸载仍可使用。

链接点击的捕获处理与原生新窗口处理拦截公网 HTTP(S)。配置的 OneAPI 来源、私有地址和本地 DNS 名称属于内网。分类不解析 DNS；额外内网域名需要明确适配。

## 考虑过的替代方案

**仅视觉禁用：** 不可用按钮无法阻止模型执行或直接 RPC。

**全局离线模式：** 禁用全部 HTTP 请求会破坏内部认证、模型和平台技能。

**删除已安装技能：** 删除会破坏切回互联网后需要的安装；过滤保留文件与本地卸载。

## 后果

互联网模式恢复被过滤的工具和技能。这是应用策略，不是防火墙或 Shell 沙箱。现有对话指令不被改写，切换环境后需新建对话以获得干净的上下文。

测试覆盖恢复、缓存技能拒绝、持久化、链接分类、I/O 前拒绝搜索及已安装 SkillHub 的可用性。Rust 测试覆盖原生链接分类。真实内部服务凭据与 macOS 原生验收仍属于部署验证任务。
