# Agent Note: 公共文件转回已记录的上传人

Status: implemented

[English](2026-11-20-public-file-return.md) | 中文

## Problem

工作台需要展示上传人，并将单个公共文件转回上传人的私有知识库。公共库创建人及操作工作台的管理员可能与文件上传人不同。

## Decision

文件清单使用已有的文档创建人记录，当前管理员上传的文件也显示姓名。目标限定为该上传人尚未发布、没有分类的个人知识库，目标列表请求设置 15 秒超时，请求失败后结束加载并在弹框内显示错误。提交时后端重新校验归属。转回复用已有移动流程，检查容量并在同名时保留两份。目标上传人记录必须保存成功，才能删除源文件。

## Alternatives considered

**上传人未知时使用库创建人或当前操作人。** 这些身份可能属于不同人员。缺少记录时隐藏操作，目标列表为空时需先创建个人库再重试。

## Consequences

转回在目标上传成功后删除公共源文件，并保留上传人身份。远端删除源文件失败时，沿用移动错误提示说明目标副本已保留。该操作只移动单个文件。
