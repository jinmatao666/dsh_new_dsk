# Agent Note: 图像专家任务流程与文档导出

Status: implemented

[English](2026-10-29-image-expert-task-workflows.md) | 中文

## Problem

图像工作台需要支持重复分析、历史删除及可理解的导出。单图 OCR 无法处理常见 PDF，变化区域数量上限过低会阻止较大影像范围的有效筛查。

## Decision

每个专家独立持有复制的资源、认证、SQLite 记录及工作进程。已完成任务可复用输入修改设置；同用户替换任务会新建运行目录并替换历史记录。运行中的记录不能替换或删除。删除已结束记录会移除文件，被替换的孤立目录一天后清理。

OCR 在本地按限额渲染文档页面，保留原始文件名和页码，仅对纯文字 PDF 页读取已有文字层。混合页面仍走 PaddleOCR。Word 导出为文字，不还原原始版式。目标检测对常见中文类别做本地转换，保守过滤近乎相同的重复检测，并同时导出原图像素框及相对坐标。

变化筛查先估计有界平移，再尝试相似变换，同尺寸图片允许沿用原位置。ECC 的逆映射会转换成对外提供的前期到后期变换。候选分批处理取消了8处区域报错，网格合并限制显示区域数。颜色补偿和过滤减少噪声，但不声称语义识别准确。对比图和热力图提供人工核对依据。

## Alternatives considered

**在原运行目录中覆盖输入文件**可能让旧工作进程把结果写入重跑任务；新目录可隔离这种冲突。

**读取所有 PDF 的文字层**可能漏掉扫描或混合页面图片中的文字，含图片或矢量绘图的页面继续走 OCR。

**把每处像素差异视为真实地物变化**会误判阴影和季节变化；筛查导出视觉证据，并明确语义准确性需要在真实影像上验收。

## Consequences

专家保持独立部署，保留现有项目名和数据卷。OCR 增加本地渲染及导出依赖。沿用原位置可能产生假差异，颜色归一化可能抑制大范围变化。去重也可能过滤非常相似的重叠目标。推理服务仍单独部署，模拟服务测试不能证明 GPU 推理准确率。

## Testing

Python 测试覆盖真实工作子进程、任务归属、替换删除、文档导出、PDF 原文字层、混合页面、去重、原图坐标及已知位移恢复。OCR 前端检查覆盖静态选择器、相对 URL 和安全文本渲染。真实 Paddle/SAM3 推理及 Buddy 原生下载仍需生产验收。
