# Agent Note: 无需发现即可手动配置模型 ID

Status: implemented

[English](2026-10-24-manual-channel-models.md) | 中文

## 问题

部分上游服务提供推理接口，却没有模型列表接口。强制获取列表会阻止管理员配置已知的模型 ID。

## 决策

渠道允许保存空模型列表，且不创建空模型名的路由记录。单个模型新增要求来源渠道存在、模型 ID 非空，但允许 ID 不在该渠道的发现清单内。可编辑的模型选择框将已有 ID 作为建议，失焦时保留输入内容。保存复用已有来源绑定 API。

本决策放宽[按渠道配置模型](2026-10-21-channel-model-configuration.zh.md)中单个新增时的清单归属限制。批量登记仍使用已配置候选并校验归属。

## 备选方案

**先编辑渠道模型清单。** 这会增加与推理无关的前置操作。

**移除来源渠道有效性检查。** 这可能关联不存在的渠道。

## 影响

手动 ID 保存成功不代表上游支持。管理员可通过连通性测试验证可用性。既有启用及来源路由规则仍然适用。

## 测试

React 测试覆盖未获取模型时保存渠道、手动模型提交及来源绑定。使用临时数据库的 Gin 请求覆盖空渠道持久化、不存在渠道及空模型 ID 的拒绝，以及手动模型路由记录创建。
