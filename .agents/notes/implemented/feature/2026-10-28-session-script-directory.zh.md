# Agent Note: 桌面工作区中的会话脚本目录

Status: implemented

[English](2026-10-28-session-script-directory.md) | 中文

## Problem

桌面代理在生成正文或报告时会写辅助脚本和转换文件。这些文件与最终文档并排存放，反复对话后会使所选工作区难以浏览。

## Decision

OneAPI 桌面 Host 为每个具有绝对工作区路径的代理注册会话级系统提示词，要求生成的辅助脚本和中间处理文件进入 `.dsh-work/<会话ID>/scripts`，最终交付文件默认留在工作区根目录。代理首次需要脚本时创建目录，已有输入资料留在原位置。每个代理获得独立路径；代理或插件结束时撤下提示词。

## Alternatives considered

**每轮结束后移动文件** 可能破坏脚本调用、引用和用户编写的代码，也无法可靠区分用户要求交付的脚本与辅助脚本。

**改写所有 Shell 和文件操作** 需要解析多种命令语言，还可能改动用户指定的路径。会话级指引仍以用户明确指定的输出位置为准。

## Consequences

新桌面会话有固定的辅助文件位置，未使用时不创建空目录。旧文件不会迁移。这是模型指引，不是文件系统限制；代理不遵守时仍可能写到其他位置。最终文件清单仍排除未被用户要求的辅助文件。

## Testing

Loader 组合测试创建带工作区的真实代理，核对会话目录及最终文件规则，并在插件销毁后确认提示词撤下。
