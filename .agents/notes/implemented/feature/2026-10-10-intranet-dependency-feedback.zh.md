# Agent Note: 纯内网依赖反馈

Status: implemented

[English](2026-10-10-intranet-dependency-feedback.md) | 中文

## Problem

纯内网用户仍需编辑和运行脚本，但依赖不可用可能导致反复尝试公网安装，也无法清楚判断任务状态。禁用本地执行又会阻止正常的内网业务任务。

## Decision

策略保留在万维认证与网络插件中。仅纯内网添加系统提示段落，要求模型检查已安装依赖、优先使用离线包和内网镜像，并且仅在必需依赖没有替代方案时用中文解释任务受阻。后台确认的环境变化通过既有设置作用域替换提示段落；插件销毁时移除。

既有工具执行前流水线拒绝可识别的直接访问公网源的包管理命令。明确的离线选项和内网源仍可使用。配置文件和未解析的变量交给包管理器处理，不猜测其内容。执行后流水线保留原始 Shell 输出，对可识别的依赖缺失或依赖下载失败追加中文说明。原因通过普通工具结果进入对话记录和模型上下文，不增加独立弹窗或伪造助手消息。互联网模式保持不变。

## Alternatives considered

**仅弹窗提示。** 模型收不到原因，可能重试或误报成功。

**禁用全部 Shell 执行。** 会阻止已安装依赖、离线处理和内网镜像支持正常任务。

**宣称完整网络隔离。** 命令识别器无法覆盖任意脚本和 Shell 语法，网络隔离仍由基础设施负责。

## Consequences

这是尽力识别的应用反馈，不是防火墙。本地配置可能解析为公网源，不能全面阻止这类命令。模型措辞由提示词引导，不是界面确定性文本。十七项依赖策略测试、十五项已有网络测试和一项真实 Loader 组合测试通过，Host TypeScript 构建与包打包也通过。测试不进行真实依赖下载，也不能证明真实模型回复措辞。
