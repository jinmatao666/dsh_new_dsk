# Agent Note: 纯内网依赖反馈

Status: implemented

[English](2026-10-10-intranet-dependency-feedback.md) | 中文

## Problem

纯内网用户仍需编辑和运行脚本，但依赖不可用可能导致反复尝试公网安装，也无法清楚判断任务状态。禁用本地执行又会阻止正常的内网业务任务。

## Decision

策略保留在万维认证与网络插件中。仅纯内网添加系统提示段落，要求模型检查已安装依赖、优先使用离线包和内网镜像，并且仅在必需依赖没有替代方案时用中文解释任务受阻。后台确认的环境变化通过既有设置作用域替换提示段落；插件销毁时移除。

提示词归属与普通工具结果反馈仍保持有效。[按实际失败反馈依赖问题](2026-10-11-failure-driven-dependency-feedback.zh.md)取代下载拒绝决策：配置为纯内网模式仍允许实际下载，由执行后诊断决定失败说明。原因通过普通工具结果进入对话记录和模型上下文，不增加独立弹窗或伪造助手消息。互联网模式保持不变。

## Alternatives considered

**仅弹窗提示。** 模型收不到原因，可能重试或误报成功。

**禁用全部 Shell 执行。** 会阻止已安装依赖、离线处理和内网镜像支持正常任务。

**宣称完整网络隔离。** 命令识别器无法覆盖任意脚本和 Shell 语法，网络隔离仍由基础设施负责。

## Consequences

这是尽力识别的应用反馈，不是防火墙。模型措辞由提示词引导，不是界面确定性文本。当前失败分类和针对性验证由[按实际失败反馈决策](2026-10-11-failure-driven-dependency-feedback.zh.md)负责。测试不能证明真实模型回复措辞。
