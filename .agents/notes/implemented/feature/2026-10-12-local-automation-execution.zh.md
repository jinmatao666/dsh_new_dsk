# Agent Note: 本机自动化执行

Status: implemented

[English](2026-10-12-local-automation-execution.md) | 中文

## 问题

如果任务开关只改变已挂载的界面状态，桌面自动化页面就无法交付定时工作。用户需要持久配置及实际执行证据，而不是示例卡片或伪造的成功状态。

## 决策

独立自动化插件拥有本机任务存储、按账号隔离的 RPC、到期任务领取和运行记录。现有会话控制器与 Agent 服务负责执行。每次运行在配置的工作目录新建会话，使用所选模型路由或默认模型。任务默认完全访问且审批策略为 `never`；用户可选择工作区写入与审批。任务模型使用 `saveAsDefault: false`，不改变普通对话默认值。安全提醒放在权限浮层内。

执行会话归属所选工作区并显示在其侧边栏分组中。执行通过普通工作区注册表注册所选本地文件夹。启动时不改变归档成员关系，已有归档仍由用户管理。运行记录导航继续打开关联会话。[检查点决策](2026-10-15-automation-execution-checkpoints.zh.md)约束前置条件报告、进度保留和完成核验。历史筛选框保留文字与箭头间距，不修改共用 Select 组件。

调度器在执行前提交下次发生时间和执行中记录。文件锁串行化阻止多个桌面进程并发领取同一任务。启动和账号变化跳过错过的计划；退出登录和卸载停止接收执行。成功依据已完成回合记录，发布最终记录前执行会话刷新。

[独立页面决策](../architecture/2026-10-10-independent-wanwei-pages.zh.md)继续约束包归属和展示。本记录只取代其中自动化仅演示的行为；连接器仍独立存在。

新建入口仍由 Client 管理。模板生成可编辑草稿，供明确确认，而不是已保存的示例任务。确认后创建已启用任务；编辑保留原启停状态。从任务新建清除当前选择并预填新对话前缀，不发送、不保存。这个导航入口本身不提供通过对话保存定时任务的工具。

新建控件使用五个 Lucide 0.468.0 SVG 图标，并保留 ISC 授权声明。固定图标区域和居中的触发区域避免字体基线偏移；菜单文字保留正常的可访问名称。紧凑下拉菜单与整个组合按钮对齐、等宽，间隔两像素。浏览器组件检查验证菜单对齐，不使用真实任务数据。

工作区选择使用工作区控制器和共用目录选择器，不提供手填路径。编辑器保存所选路径，不导航或注册工作区；取消和失败保留草稿。编辑器浮层通过 body portal、视口边界限制和共用产品图标呈现；日历与有效期字段右边缘对齐。本地日历调度支持间隔、单次以及每天至每年周期和包含结束日的有效期；耗尽的任务在领取执行时暂停。替换已保存任务会移除已清空的可选模型和日期字段。运行台账通过已提交的时间戳计算耗时，不宣称产物成功。不提供通知发送功能。

任务与记录搜索在各自顶部原位展开。台账行通过鼠标或键盘打开关联会话；失败详情及删除控件不触发导航。按账号隔离的记录删除使用现有加锁存储，并在修改内部拒绝执行中记录，保留跨进程防重复执行判断。确认框说明任务、会话和文件均保留；删除历史不停止执行。组件测试覆盖搜索位置、导航及确认；Loader 组合测试覆盖持久删除、账号拒绝和执行中记录拒绝。

## 考虑过的替代方案

**保留演示：** 无法满足真实调度要求，也会隐藏已配置工作与实际执行之间的区别。

**增加云端调度：** 需要另行授权的执行环境和用户文件访问。本次范围是本机执行。

**实现另一套 Agent 循环：** 会重复模型、权限和会话行为。调度改为委托现有公开控制器。

## 影响

关闭页面和重启桌面端后任务仍保留，但桌面端必须保持运行和登录。错过的工作不补跑。存储损坏明确报错；遗留文件锁需要运维恢复。Agent 回合完成不等于独立证明所生成文档在语义上正确。

专项测试验证初始空界面、写入失败、持久账号隔离、工作日周期、Loader 挂载、真实会话与 Agent 执行、定时领取、重复执行拦截和超时记录。外部模型响应及桌面传输使用测试替身；真实模型和原生桌面验收仍需在部署环境手动进行。
