# Agent Note: 内网中转获取指定网站资源

Status: implemented

[English](2026-10-24-specified-resource-retrieval.md) | 中文

## Problem

遵循代理的依赖客户端不能为模型提供从用户指定网站到本地文件交付的可靠路径。内网部署仍独立限制原生网页读取，全局替换传输可能改变认证、模型和专家服务流量。

## Decision

万维私有资源路由器为内网中转的新 Shell 命令生成标准库 Python 模块。模块读取有上限的网页正文和实际链接，或下载到显式工作区路径，执行证书验证、跳转及字节限制、哈希、排他原子发布和失败清理。它继承现有正向代理或认证通道及自动检测。离线模式移除模块搜索路径，不切换来源。模型提示说明实际命令并将网页内容视作不可信数据；被拦截的公网 web_fetch 提示改用该命令。不新增后台传输 API 或通用浏览器代理。普通 Shell 沙箱、执行日志及最终文件交付仍是权威路径。

## Alternatives considered

全局 Node dispatcher 可能意外路由平台凭据，且不覆盖浏览器。为私有产品需求新增二进制文件系统 API 或下载工具会扩大官方能力契约。Shell 客户端保留现有沙箱和代理所有权，代价是依赖内置 Python，不执行 JavaScript 网站或转移浏览器登录状态。

## Consequences

后台页面说明网站及文件获取；桌面构建必须包含模块。不宣称支持原生搜索、任意浏览器流量、验证码或需登录的网站流程。本地真实 Python 冒烟覆盖不依赖目标 DNS 的测试代理、网页链接、跳转、二进制内容、路径及覆盖拒绝、HTML 冒充、大小限制和清理。Vitest 行为与 Loader 快照检查已通过。生产通道和安装版验收仍按[资源指南](../../../../products/wanwei-desktop/resource-relay/README.zh.md)由发布阶段检查。
