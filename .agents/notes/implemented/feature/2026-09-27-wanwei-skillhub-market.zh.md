# Agent Note: 万维技能市场接入 SkillHub

Status: implemented

[English](2026-09-27-wanwei-skillhub-market.md) | 中文

## 问题

用户需要在平台技能旁浏览公开第三方技能，同时避免来源混淆、本地技能覆盖以及官方 Harness 与远端市场的耦合。

## 决策

万维 SkillHub 插件负责公开目录、图标与指定版本技能包请求。现有产品市场通过限定范围的样式和受控 Markdown 将其展示为同级区块。平台推荐仅包含平台官方条目；两个目录各自管理搜索。SkillHub 卡片沿用平台卡片结构，详情以完整页面显示并保留列表位置。Host 只代理腾讯图像主机上大小受限的栅格图标。桌面端暂存导入，在启用目录前写入来源记录，并拒绝覆盖其他来源的同名技能。手动更新必须匹配同一远端身份及本地安装记录，在新版本发布成功前保留旧版本。本地记录支持离线列举和卸载；调用使用实际安装名称。

两个目录分别管理搜索、分类、排序及每页十二张卡片的分页。翻页控件放在各自筛选条件旁，而非整个市场底部，避免被误认为整页导航。共享工具栏和下载图标让两个来源保持视觉一致；区块标题标识 SkillHub，无需在每张卡片重复名称。平台更新排序使用服务端时间，不从版本号推断日期。

我的安装将平台及本地条目与 SkillHub 安装记录放在同一个按来源筛选、每页十二张卡片的列表中。统一工具栏管理搜索和页码，选择全部技能不会渲染两套独立分页列表。卸载后本地安装记录刷新重新计算页数，无需查询 SkillHub。

## 考虑的替代方案

**嵌入上游网站**会引入另一套导航和样式，也无法整合本地安装状态。直接适配 API 保留现有市场。

**让 OneAPI 认证承担 SkillHub 接入**会耦合独立上游。独立产品插件让可用性和协议所有权相互独立。

## 影响

SkillHub 结果提示不等待安装记录刷新。进度提示持续显示到结果替换，成功和错误提示则自动消失。两个来源使用白底、中性正文、系统无衬线字体和简洁结果措辞，仅状态图标保留语义颜色。安装记录刷新失败与安装、卸载失败分别说明。

官方智能体循环保持不变。本次交付同时包含技能调用需要的通用草稿暂存与前缀展示扩展；客户端接口不包含 SkillHub 业务逻辑。根目录工作区元数据登记新增产品包。平台安装器的所有权检查拒绝 SkillHub 记录，包括仅按名称识别旧技能的路径。付费技能、自动更新和自动安装依赖不属于此功能。其他主机的图标使用本地默认图形。生产上线前需要确认 API 商用条款和未来凭据要求。

[产品边界决策](../architecture/2026-09-20-wanwei-extension-boundaries.zh.md) 继续有效；此功能增加产品数据源，不替代该决策。

产品品牌组件使用 -100 优先级与官方品牌插件共存；相同默认优先级会阻止组合后的市场加载。
