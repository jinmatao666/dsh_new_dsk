# Agent Note：没有直连互联网时禁用出网功能入口

状态：已实现

[English](2026-10-21-intranet-outbound-entry-availability.md) | 中文

## 问题

内网用户需要看见自动化和连接器入口，但不应打开页面后才看到大型不可用插画。仅凭部署模式无法区分可直连互联网的机器与依赖中转或离线资源的机器。

## 决策

部署确认时将资源路由缓存的直连检测结果发布给 Client，不引入第二套检测实现或中转连接。内网模式下，自动化和连接器入口要求启用直连检测且检测成功。关闭检测、使用离线资源、检测失败或尚未确认时，入口置灰且不可点击，提示“当前网络环境不可达，请检查您的网络”。中转不算直连。外网模式行为和管理员显式可见性配置保持不变。

共用面板阻止其他入口打开不可用页面，并在可用性丢失时关闭活动页面。确认恢复后启用入口，但不自动重新打开页面。既有认证刷新触发器更新结果，不改变原生网络模式或后台任务调度。

## 考虑过的替代方案

浏览器在线状态不能证明公网可达；检测后台只能证明后台可达。另建检测和缓存可能导致资源路由与侧边栏判断不一致。复用 Host 决策，保留直连可用性的统一含义。

## 影响

测试覆盖关闭检测、直连成功与失败、缓存、快照校验、禁用点击和恢复。桌面 profile 浏览器回归验证内网下保留置灰入口及完整提示，同时专家与技能页面仍可使用。管理员隐藏的入口仍保持隐藏，不被连通性检查恢复。
