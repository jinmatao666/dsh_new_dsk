# Agent Note: 基于已记录行为的管理员用户画像

Status: implemented

[English](2026-10-24-admin-user-profile.md) | 中文

## Problem

管理员用户列表展示账户状态和累计请求次数，但无法看出单个用户如何使用模型、技能和专家网站。按用户名在全局统计页拼接数据，可能混入改名账户或其他人的记录。

## Decision

仅管理员可访问的[画像接口](../../../../services/one-api/controller/user_profile.go)按本地用户 ID 汇总最近 30 个北京时间自然日的模型消费日志、技能调用事件和专家任务启动事件。技能下载和已记录的安装使用现有的用户累计计数。[用户列表弹窗](../../../../services/one-api/web/air/src/pages/Zjugis/UserProfile.js)展示统计区间、次数、每日趋势、项目排行和规则化文字摘要。不读取提示词、文件或对话，也不推断个人属性。

## Alternatives considered

**在浏览器按用户名拼接现有全局使用接口。** 用户名可能改变，全局接口也不提供单人模型及下载汇总，前端筛选会暴露不必要的记录。

**用 AI 自由生成描述。** 行为计数不足以推断兴趣或职业角色。弹窗只描述可核对的已记录事件。

## Consequences

点击用户行即可查看画像，令牌管理操作保持不变。模型统计依赖消费日志启用；缺少记录不等于没有使用。下载采用累计口径，其余数据采用 30 天口径。接口有用户隔离和日期窗口测试，弹窗有行点击测试。
