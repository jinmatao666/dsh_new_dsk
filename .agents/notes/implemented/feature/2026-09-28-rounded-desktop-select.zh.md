# Agent Note：桌面端圆角下拉框

状态：已实现

[English](2026-09-28-rounded-desktop-select.md) | 中文

## 问题

桌面端原生 HTML 选择框的触发框虽有圆角，但 Windows 会把选项弹层绘制成直角的系统菜单，与产品里的其他控件显得脱节。

## 决策

共用 UI 基础组件提供使用主题变量的单选 `Select`，选项以圆角浮层展示。技能市场筛选、我的安装来源筛选、新增技能、连接器与自动化表单，以及模型提供方设置都使用这一组件。已有独立样式的菜单保留各自的交互约定。

触发框保持焦点，支持方向键、Home/End、Enter、空格和 Escape。弹层在滚动或窗口缩放时跟随触发框，并根据窗口空间选择上下位置。面向用户的标签和选项仍由产品插件提供本地化内容。

## 验证

组件测试覆盖鼠标及键盘选择、点击外部关闭和禁用状态；技能市场与模型设置测试覆盖迁移后的调用。安装包内的 Windows 视觉复核仍需确认尺寸与遮挡情况。
