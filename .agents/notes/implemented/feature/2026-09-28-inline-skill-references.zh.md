# Agent Note: 行内技能引用

Status: implemented

[English](2026-09-28-inline-skill-references.md) | 中文

## 问题

独立技能横栏在问题上方重复显示 slash token，并占满一行。市场导航和菜单选择需要统一的紧凑展示，且不得改变宿主技能加载。

## 决策

技能菜单选择使用原子引用，其 codec 输出原始 slash token。通用草稿前缀 Slot 行内渲染暂存前缀，并把普通前导文字转成会话引用。万维负责友好名称查询和胶囊样式；共享原子组件提供技能图标。

## 考虑过的替代方案

**仅调整独立横栏样式。** slash token 仍重复显示，问题仍在另一行。

**从提交消息删除 slash token。** 宿主加载需要该 token；展示不能改变执行。

## 影响

用户可在暂存技能旁编辑问题，会话引用序列化为 `/name`。手动 token 保持文字装饰，除非产品展示器识别它。技能标签仅属于编辑器；持久化草稿文字可经产品展示器恢复。官方模块不包含产品名称、存储键或主题规则。

## 验证

输入框专项测试覆盖前缀转换、暂存问题编辑和提交 slash token。产品测试覆盖 SVG 标签、移除不触发导航及会话交接。运行中桌面的视觉对照仍需人工验证。
