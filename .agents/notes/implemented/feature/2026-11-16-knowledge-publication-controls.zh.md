# Agent Note: 发布撤回与订阅积分上限

Status: implemented

[English](2026-11-16-knowledge-publication-controls.md) | 中文

## Problem

个人知识库所有者需要停止共享已发布的知识库并保留文件。管理员也需要限制每文件单价，并查看审核申请中的资料。

## Decision

只有所有者可撤回已审核通过的发布。OneAPI 在一个事务中清除公共或订阅共享范围及相关申请和授权。重新发布需要再次审核。原库和积分使用凭证保留。运营版侧栏个人入口显示所有者名称，共享入口显示「万维」。

管理员在同一份策略中保存平台比例和三项上限，金额以百分之一积分计。服务端拒绝超过对应上限的新单价，并在新报价和结算中对已有单价限价。上限为零时对应操作免费。已经结算的凭证保留原金额。

审核弹窗通过申请对应的管理员接口读取文件。文件页签按页加载，预览复用工作台查看器。

## Alternatives considered

仅隐藏共享卡片会保留直接访问和原有授权。仅在桌面表单校验价格会让旧客户端仍可提交或结算较高单价。

## Consequences

所有者保留文件，撤回后可以重新发布。撤回的订阅库重新发布后，订阅者需要再次申请。管理员可以核对源文件，同时保持库的访问权限。
