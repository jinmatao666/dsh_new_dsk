# Agent Note: 资规讲坛使用桌面端模型选择器

Status: implemented

[English](2026-11-23-forum-desktop-model-analysis.md) | 中文

## 问题

嵌入式资规讲坛需要使用桌面端选中的模型分析文章。登录票据用于识别用户，不授予模型访问权限。会话的模型选择可以与全局默认值不同。

## 决策

[门户 Client](../../../../packages/wanwei/portals/src/client/plugin.tsx) 在每次提问时读取当前会话的模型目录，尚无会话时读取草稿目录。只有桌面父窗口向已认证的 Host 流接口 提供模型选择。嵌入页面通过同时校验来源和 iframe 身份的桥接提交正文、问题及已完成的历史对话。凭据保留在 Host。

对于未命中已保存答案的提问，Host 创建独立 agent（智能体），使用完整分析提示词，不附加环境提示上下文，也不开放工具。正常会话事件保留完整输入、请求头和回答。输入限制拒绝超限数据，不静默截断。取消和释放操作会停止并等待所属 agent 结束，再释放请求容量。讲坛显示完整回答，并标明上一次回答使用的模型。[讲坛计费](2026-11-23-forum-analysis-billing.zh.md) 持有配置价格和持久化答案复用的决策。

## 考虑过的替代方案

**在讲坛后端配置共享模型 API Key。** 此方案需要独立授权及计费，也无法跟随桌面会话所选模型。

**只读取桌面全局默认模型。** 桌面会话和草稿选择器可以保存独立选择而不修改默认值，因此由父窗口选择器提供实际模型。

**直接使用桌面通用 agent。** 文章是不受信任的参考资料；共享具备工具能力的会话会暴露无关上下文和工具权限。独立且禁用工具的会话既保留日志，也限制权限。

## 影响

桌面端和讲坛前端必须同步更新。独立浏览讲坛时没有分析桥接。长文或较长历史需要缩小请求范围或清空对话；本功能不获取缺失的外链正文。推理仍受提供方可用性和账号模型权限限制。

## 验证

包内 Loader 组合覆盖模型选择、输入日志、工具排除、长度限制、取消和超时。桥接测试拒绝其他来源或 iframe，并丢弃迟到结果。Web 录制会话场景固定分析提示词，并验证经已认证 Host RPC 的完整往返。
