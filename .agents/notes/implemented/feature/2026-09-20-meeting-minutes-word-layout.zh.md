# Agent Note: 会议纪要使用独立 Word 版式

Status: implemented

[English](2026-09-20-meeting-minutes-word-layout.md) | 中文

## Problem

会议纪要技能原本使用通用 Markdown 转 Word 排版器生成最终文档。内容虽然完整，但 Letter 页面、平均分配的表格列宽、字符形式的项目符号以及通用标题间距降低了长篇纪要的可读性，待办事项表尤其拥挤。

## Decision

会议纪要技能在通用 Markdown 排版器生成 DOCX 后执行专用格式化。该处理保留生成文本，只调整表现形式：A4 纵向页面、居中的会议副标题、黑色标题层级、原生列表段落、克制的表格底色、按内容分配的列宽、跨页重复表头和紧凑页码。其他办公技能继续使用通用排版器，不执行该格式化。

## Alternatives considered

**修改通用 Markdown 排版器** — 不采用，因为文档摘要和文档对比报告有不同的版式需求，会议纪要专用列宽会损害这些产物。

**通过模型提示词控制全部格式** — 不采用，因为语言模型可以控制 Markdown 结构，但无法可靠设置 DOCX 页面尺寸、表格列宽、单元格边距和跨页重复表头。

## Consequences

会议纪要获得稳定的正式版式，同时保留相同的事实内容和输出文件类型。技能只增加一个 DOCX 后处理函数，后续会议纪要专用排版调整不会影响通用办公文档渲染。
