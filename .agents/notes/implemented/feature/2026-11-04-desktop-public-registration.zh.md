# Agent Note：桌面公开注册与统一登录

状态：已实现

[English](2026-11-04-desktop-public-registration.md) | 中文

## 问题

短信和扫码入口仅提示不可用。公开注册未采用管理员指定的默认角色，短信校验忽略手机验证码有效期配置。

## 决策

现有登录卡片接入固定Host短信登录、明确确认的注册、找回密码和微信扫码。未注册手机号须同意协议，密码选填；已有手机号保留账号ID和角色。未绑定账号的微信先手机号登录或注册再绑定。已有微信账号缺少已验证手机号且不具备用户名密码凭据时，通过Host持有的短时Cookie补绑原账号。离开页面取消请求，更换二维码废弃旧状态。

新公开注册由服务端分配角色，未指定时按名称匹配已有“注册用户”。只接受启用的普通成员角色，默认角色不能直接删除、停用或在按名匹配时改名。已有账号及管理员创建用户的角色逻辑不变。后台提供仅超级管理员可改的登录配置和同页默认角色选择，其他工作台配置权限不变。短信执行配置有效期、一分钟发送间隔和每小时上限。

桌面扫码入口现已接入公开认证能力，后台启用后展示服务端生成的微信二维码。超级管理员可在登录配置中设置 WeChatAppID、只写的 WeChatAppSecret、WeChatAuthEnabled 和可选的完整 WeChatCallbackURL。回调覆盖值独立于后台 API 地址，可同时使用 HTTPS 回调与现有 HTTP 桌面 API；留空则沿用 API 地址生成回调。回调配置拒绝账号密码、查询参数、片段及 /api/oauth/wechat 以外的路径。二维码解析失败时返回可读提示并删除待处理状态。账户设置中的微信绑定入口仍暂未开放。

新手机号确认协议并验证后直接进入主界面，再通过原生弹窗可选设置密码。服务端提供十分钟内单次有效的首次设置资格，不重复发短信，已有密码的账号拒绝此接口；后续改密沿用验证流程。资格保存在进程内，重启或请求到其他副本时需走普通账户设置流程。后台同页分为注册、短信和协议三个区，开关使用开启／关闭下拉框，隐藏固定技术参数。登录表单字段和按钮位置及底部三行文字统一，无内部滚动条。

后台短信登录下拉框保存时同步 PhoneLoginEnabled 与 SMSEnabled，短信签名隐藏并保留。账户安全操作使用随包许可图标和可键盘聚焦的绑定手机号提示。积分明细保留变动后余额，并增加首页／末页及有范围校验的页码跳转。

短信提交采用页面“登录即表示同意”的确认方式，不再要求单独勾选。底部链接以原生顶层弹窗展示版本化内置协议和隐私文档，无需联网。服务端注册仍要求确认同意，但不再依赖可选后台正文；后台提示文档随客户端版本发布。文档以万维Buddy作为服务名称，联系请求通过登录页管理员入口提交；正文采用完整的用户条款，不保留占位邮箱或未经核实的部署细节。选项行提示验证码五分钟有效，账号、连接、短信、找回密码异常及扫码未开放提示统一通过可关闭的原生弹窗展示，避免与页脚重叠；关闭提示保留表单输入。

已有用户名和密码的账号可在扫码后验证原账号并绑定微信，无需绑定手机号。后续扫码仅对同时具备受管用户名和密码凭据的账号免除补绑手机号；新用户注册仍需短信验证手机号，只有用户名但未设置密码的账号仍需验证手机号。数据库读取异常不会授予豁免。

桌面二维码区域以内嵌页面加载微信官方授权页，采用腾讯 wxLogin.js 发布的 iframe 参数（login_type=jssdk、self_redirect=true）。单独的二维码图片无法执行微信确认轮询和回调跳转。Host 在暴露嵌入地址前校验授权来源、路径、state 和回调地址；应用轮询继续完成 Host 持有的登录会话，加载授权页本身不代表登录完成。真实扫码仍需联调验收。

扫码卡片将授权区域、操作提示与刷新入口限制在固定登录内容高度内。未绑定身份通过独立原生弹窗验证手机号或绑定已有用户名密码账号；关闭弹窗重新获取二维码状态，不绕过验证。

二维码过期在授权区域显示遮罩与刷新入口，停止状态轮询，不弹错误框；服务异常仍通过原生弹窗展示。

## 考虑过的替代方案

未注册登录时自动建号会跳过协议确认。已有微信账号再次建号会分裂身份。按编号推断角色可能授错权限。只在页面限制配置不能保护直接接口调用。

## 影响

后台和桌面须同时更新。阿里云凭据、审核通过的签名和模板、微信网站应用及可访问的回调地址、最终协议和隐私政策正文仍需配置，未擅自启用。没有发送真实短信、执行微信授权或修改生产账号。测试使用隔离SQLite账号中心表和模拟认证返回。默认分配需要已有启用的“注册用户”，或明确指定其他普通成员角色。

## 测试

专项测试覆盖登录／令牌／模型兼容、短信注册会话建立、协议确认、注册引导、找回密码、取消请求和微信补绑手机号。后台测试验证角色分配、老账号保留、验证码单次使用、密码重置持久化、配置权限、已认证短信／限流及有效期。后台页面测试验证只保存变更项、保留密钥、失败重试、默认角色选择及原有系统页签。类型检查、专项lint和浏览器PNG预览验证修改面。短信送达和OAuth须配置后实测，尚未验证。

账户设置现已开放微信绑定，复用公开登录中经过校验的微信授权页面。扫码确认后，用户明确提交绑定至当前已登录账号；已有手机号的账号仍需验证短信，尚未绑定手机的旧账号可通过当前已登录会话关联。解绑保留手机验证。二维码过期停止轮询，并在原位置显示刷新操作。绑定成功重新读取账户状态，不改变用户名或当前会话。
