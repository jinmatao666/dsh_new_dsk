# Agent Note: 桌面版本设置与下载进度

Status: implemented

[English](2026-10-20-desktop-version-settings.md) | 中文

## 问题

账户设置将身份管理与原生更新混在一起，并在账户页嵌入下载进度。离开页面后进度消失，而自动更新可能在设置之外开始。

## 决策

客户端以顺序 35 在顺序 40 的账户之前注册版本页，并单独注册壳层进度弹窗。插件生命周期内的一个控制器串行轮询原生状态，将快照共享给两个视图。进入下载或安装阶段时打开顶层 HTML dialog。收起下载仅改变展示；重复轮询不重新打开弹窗，版本页提供手动重开入口。安装弹窗不可关闭。字节数和百分比来自原生状态；总量未知时使用不确定进度。

界面保留现有蓝白配色，采用紧凑版本区域、无障碍开关及明确的检查按钮。原生下载和安装确认、签名及最终繁忙拒绝保持不变。展示调整不授予安装权限。

同版本重发使用后台独立上传记录和平台当前发布指针。启动时移除旧的平台／版本唯一索引，不删除历史。服务端检查和原生更新器均允许相同版本。签名清单绑定与编译后桌面壳一起导出的构建标识，能识别当前正在运行的包，手动安装后也适用。文件 SHA-256 安装记录同样避免重复安装。更低版本仍不允许自动安装。

启动安装器前，桌面壳持久化目标版本、更新说明及来源／目标构建标识。后续启动只有目标版本和目标构建运行才将待安装记录确认为完成；不含目标标识的旧清单要求来源构建发生变化。安装失败而重启来源构建不会误报成功。监视器用可关闭的顶层 HTML 弹窗展示未读说明；关闭时先持久化，再隐藏，轮询和后续重启不会重新打开。未具备此机制的旧桌面壳须先更新更高版本或手动安装。原生跨平台安装器验收仍独立于本地测试。

## 考虑过的替代方案

**将监视器放在版本页内：** 关闭设置会移除监视器，不能在其他位置显示自动下载进度。

**两个视图独立轮询：** 独立状态和操作可能不一致或重复发出命令。单个共享控制器持有轮询并随插件清理。

## 影响

账户页仅保留身份管理。关闭版本页不会中断监视或下载。纯浏览器组合不显示可执行控件。卸载后的在途或过时响应不能发布状态。浏览器预览使用模拟原生状态，不运行真实安装程序。

## 测试

包内测试覆盖开关持久化、原生命令及故障、页面卸载、弹窗收起重开、未知总量、拒绝关闭安装及轮询清理。Loader 组合检查真实客户端注册、顺序与共享监视器身份。浏览器检查使用真实视图，验证弹窗焦点、Escape、窄窗口布局及进度不嵌入设置正文。各平台安装版升级仍需验收。
