# Agent Note: 知识库操作日志

Status: implemented

[English](2026-11-20-knowledge-activity-history.md) | 中文

## Problem

知识库和申请数据表示当前状态。重命名知识库或重复申请后，这些数据无法完整表示稳定的历史记录。

## Decision

OneAPI 追加保存操作日志，包含知识库名称、相关人员编号、时间和结果。创建、知识库删除、分类删除及审核日志随业务事务一起提交。文件删除在远程移除前保存文件名，成功日志与本地元数据清理一起提交。远程删除失败不会产生成功记录。文件转入成功后记录来源与目标名称，日志保存失败则明确返回部分成功的错误。超级管理员可查看全部日志，其他管理员可查看自己操作或自己拥有的知识库相关记录。

## Alternatives considered

从申请数据推导日志会在申请被替换或撤回时丢失结果。独立日志在知识库删除后仍然保留，没有保存日志的操作无法查询。

## Consequences

部署自动创建日志表。全部操作合并为一个按时间分页的列表。服务端先在调用者可查看的范围内按知识库、文件和相关人员搜索，再统计数量和分页。操作单元格对应展示操作人或审核人，创建人和申请人分别标注。远程文件操作与 SQL 日志无法共用事务。姓名取自当前身份数据，无法解析时展示用户编号。
