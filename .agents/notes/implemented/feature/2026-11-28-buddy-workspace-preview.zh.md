# Agent Note: Buddy 工作区文件预览

Status: implemented

[English](2026-11-28-buddy-workspace-preview.md) | 中文

## Problem

Buddy 需要迁移 Parvis 的工作区文件流程，同时保持上游界面包可独立升级。

## Decision

工作区编排放在万维 React 产品层，受限文件系统命令放在产品原生壳。Parvis 原版 Solid 预览组件通过隔离 iframe 运行，提供本地适配、内置样式及离线 PDF 资源，原始许可编入运行时。Word、PDF、工作表、幻灯片、图片及选区行为复用原版渲染器；Markdown、HTML 提供本地渲染及沙箱适配，文档相对图片和样式表由有权限的宿主嵌入。

文件树使用 Parvis 图标，支持展开、搜索、指针拖拽引用、文件操作和切换打开文件。独立草稿在切换工作区时保留在内存。Word 选区替换可跨文本段保留格式。模型改写及 Word 图表插入使用当前会话，将请求与对应已完成响应关联，先生成可审阅草稿。保存校验原始摘要并原子替换文件；删除将内容移到工作区隐藏的 .buddy-trash 文件夹。

## Alternatives considered

简化 React Office 渲染器会丢失合并、样式、幻灯片及选区行为；整体引用 Parvis 应用又会依赖其后端和会话系统。隔离的产品预览模块保留相关实现，无需改动上游包。

## Consequences

产品界面与原生壳需要一起重建。DOC、PPT 仍需要 LibreOffice 或 SOFFICE_PATH，新版 Office 格式直接渲染。文件树可见时每三秒检查变化；搜索限制为 150 个目录、5000 项结果，单文件读取限制为 24 MiB。草稿保留在内存，退出应用不会持久保存。显式模型编辑按正常模型用量计量。

浏览器检查覆盖 Word、合并单元格及多工作表、Markdown、净化 HTML、图片缩放、幻灯片及连续 PDF 分页。定向测试覆盖请求关联、Word 跨文本段替换、草稿切换、资源路径边界、路径约束、冲突拒绝和可恢复文件操作。这些检查不保证所有用户文件逐像素一致，也不能替代重建桌面壳后的真实模型测试。宿主适配和复现命令见产品 preview-runtime README。

面板仅显示当前会话对应工作区，未选择时不显示。Lucide 控件替代字符图标，关闭预览仍保留文件列表。宽窗口并排显示且保留问答区宽度，较小窗口使用文件列表浮层或抽屉。XLS 和 UTF-8 CSV 直接渲染，JSON 和投影文件按文本预览。其他格式提供系统应用打开入口，Windows 打开失败后可选择打开方式；外部查看仍需要安装兼容应用。

保留上游问答末尾的产物附件栏，移除会占用并隐藏普通附件标签的通用文件卡片展示器。产品层捕获附件点击并转交当前工作区的受限预览；没有工作区接收路径时保留原有打开行为。外部应用打开入口位于预览工具栏，专业分析展示器仍独立保留。集成测试渲染真实的上游 ProducedFiles 组件，验证多文件切换、打开已关闭面板、系统应用打开、工作区外路径回退和不重复生成卡片。
