# Agent Note: 最终交付物筛选

Status: implemented

[English](2026-09-30-final-deliverable-selection.md) | 中文

## 问题

工具生成报告时可能产生草稿文本、中间 Markdown、预览图片和最终文档。把所有成功修改的文件都列为产物，会让实际交付物淹没在过程文件中。

## 决策

产物插件保留成功修改和运行输出中的路径作为已记录事实。插件把已落定的助手回复折叠进轮次级展示数据，按收尾回复的引用顺序筛选已记录路径。精确路径和唯一文件名可以解析；URI 引用要求解码后的精确路径。回复不能凭空创建文件。没有可解析引用时优先展示文档输出；否则其他非过程文件仍可展示。已知过程路径只从交付列表中排除。正文链接保留完整的已记录路径词表。

## 考虑过的替代方案

**只特殊处理一个办公技能。** 其他技能和普通对话仍会展示相同的中间文件。

**按扩展名过滤全部源码或 Markdown 文件。** 源码和 Markdown 也可能是正式交付物，所以显式交付引用仍可展示。

**自动删除中间文件。** 展示规则不能可靠识别文件生成依赖和用户已有的工作数据。筛选不授权删除磁盘文件。

## 影响

主要输出按收尾引用顺序排列，而非生成顺序。仍允许交付多个最终文件。模型遗漏引用时，文档优先规则是启发式的，可能忽略合法但未引用的配套文件；精确引用可避免该歧义。会话数据、工具历史和磁盘文件不变。回归测试覆盖只交付文档、多文件交付、过程文件过滤、有歧义的引用、回放、实时追加和加载较早历史页。
