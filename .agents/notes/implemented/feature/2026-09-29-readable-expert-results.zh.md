# Agent Note: 专家成果阅读与用户选择保存位置

Status: implemented

[English](2026-09-29-readable-expert-results.md) | 中文

## Problem

文档摘要在狭窄的并排章节里直接露出 Markdown 表格分隔符和内部来源标签。自动保存到下载目录让用户不清楚成果位置。

## Decision

独立文档专家以单栏章节、易读字号、语义列表、加粗和可横向滚动的表格展示结果。数字来源上标和来源文件标记转换为可读引用；任意 HTML 仍被转义。Word 导出渲染对应标题、列表、加粗和表格。已有 Word 文件需要重新生成任务才能改变格式。

六个网站均将经过身份校验的成果字节转发给桌面命令。只有原生“另存为”窗口选择目标位置和确认覆盖。命令校验有界字节、文件名和不变的受支持扩展名，返回已保存路径，取消返回 null。网站显示已保存路径，不将取消报告为成功。

## Alternatives considered

**保留自动保存到下载目录。** 这减少点击，但不满足用户明确选择位置的要求。

**启用任意模型 HTML。** 这保留模型格式，但会向用户暴露不可信可执行标记。有界的转义渲染器支持所需报告结构。

## Consequences

会议专家运行页使用 CSS 等待动画和基于提交时间、每秒更新的已等待时钟，不推断后端阶段或完成百分比。排队文案独立，导航、登录失效和终态渲染停止时钟。来源文件名换行，右侧栏使用更大的字号；减少动态效果偏好禁用动画。

地质、三调和规划审查结果使用各自字段和图层词表中的业务名称，突出结论与核实章节，区分依据标签并折叠技术编号。原始数值、未知代码和完整模型正文保持不变。新模型请求携带词表，并禁止补造单位或等级含义。

蓝白设计和专家导航素材保持不变。网页部署更新报告展示；原生保存窗口需要更新桌面构建。OneAPI 无需改变。浏览器下载沿用浏览器行为。Windows、macOS 和 Linux 的原生窗口交互仍需平台验收。

## Verification

前端测试覆盖表格和引用渲染、脚本文本转义、保存路径返回和取消。Python 测试检查 Word 表格和加粗。Rust 测试覆盖文件校验和用户选择位置；桌面库编译通过。本地浏览器截图检查摘要展示和窄屏溢出。
