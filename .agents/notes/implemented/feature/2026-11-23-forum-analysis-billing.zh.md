# Agent Note: 讲坛价格与答案复用由计费后端持有

Status: implemented

[English](2026-11-23-forum-analysis-billing.md) | 中文

## 问题

讲坛需要为弹框问答和生成报告分别设置后台价格。用户重新打开页面或切换桌面模型后，已回答的相同问题不能再次计费。同时收取业务操作积分和模型 token 积分会产生二次扣费。

## 决策

两个固定配置计费点默认各 1 积分。后端在执行前返回价格版本，并通过专家共用的统一计费事务预扣。持久化问题键包含账户归属、来源类型与 ID、空白归一化后的问题以及操作类型。历史对话、模型和价格变化不改变已完成答案的权威性；活动任务排除另一执行。失败和过期任务释放预扣后才能重试。

保存答案和结算任务一同提交。Host 保留本次执行凭据，确认响应不明时只重试原结果，不重新生成，也不为可能已完成的答案退款。遗留预扣通过现有统一工作线程过期退款。预扣任务仅授权该账户、会话和所选模型的一次平台文本请求。原子认领拒绝另一 HTTP 请求；同一 HTTP 请求内部的渠道重试复用原认领。模型用量保留记录，附加积分为零。临时会话使用文章标题，避免标题推理的额外模型请求。

[桌面模型选择决策](2026-11-23-forum-desktop-model-analysis.zh.md) 继续持有 iframe 校验、凭据隔离和模型工作日志的依据。[知识库结算](../architecture/2026-11-18-knowledge-unified-credit-settlement.zh.md) 独立持有按引用确定的知识库价格；这两项决策均未被取代。

iframe 仅提供提问和取消操作，价格查询和 HTTP 分析流由 Host 持有。并发结算调用等待同一个队列清理任务，不把已有清理任务当作结算已经完成。缓存答案查询后重新核对当前账户，再返回答案。

## 考虑过的替代方案

**只在浏览器内存或本地存储去重。** 刷新、其他安装和并发请求可以绕过这些状态，且无法与账户扣费保持原子性。

**预扣配置价格后继续收取 token 积分。** 这会违反所选固定价格，并可能拒绝余额刚好足够本次操作的用户。

**把调用方提供的会话 ID 当作免扣费依据。** 归属标记不代表已经预扣。后端必须检查账户所属活动任务、未过期计费任务、所选模型以及尚未使用的模型请求认领。

## 影响

桌面端、管理后端和讲坛前端同步部署。成功答案没有缓存到期时间；来源内容编辑后仍沿用原来源和问题的身份。如果 Host 无法持久化已完成的答案，会报告结算尚未确认并重试原结果；Host 崩溃可能丢失未保存答案，预扣最终过期退款。生成报告在抽屉内返回分析文本。[讲坛说明](../../../../packages/wanwei/portals/README.zh.md) 持有操作行为的当前定义。

## 验证

定向覆盖检查带版本的改价、两项独立价格、账户隔离、持久化答案复用、重复执行、模型认领防重放、退款、余额不足以及不再额外扣模型积分。Host 测试覆盖结果确认重试，Client 测试覆盖直接发送、实时文本更新和 Markdown 清理。后端从问题措辞识别报告生成请求；页面不展示报告按钮或积分确认。录制会话固定禁用工具的模型输入和标题事件。
