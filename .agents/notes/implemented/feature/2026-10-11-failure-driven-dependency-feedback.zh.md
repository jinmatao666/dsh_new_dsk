# Agent Note: 按实际失败反馈依赖问题

Status: implemented

[English](2026-10-11-failure-driven-dependency-feedback.md) | 中文

## Problem

配置为纯内网不代表互联网实际不可达。按模式拒绝依赖下载会阻止可正常执行的任务，而缺少 PowerShell 反馈又让 Windows 失败原因不清楚。环境修复脚本还可能出现在产物列表中。

## Decision

万维网络插件在两种模式下均允许包管理器执行。仅纯内网模式对可识别的 Bash、PowerShell 和终端诊断追加失败指引。原始输出保持完整；模块缺失、连接失败和依赖源未找到包分别反馈。权限或语法错误本身不代表网络失败。模型被引导简短说明依赖、原因和处理建议，只停止被依赖阻塞的步骤，避免未经请求的环境修复或换源。这部分取代[下载拒绝决策](2026-10-10-intranet-dependency-feedback.zh.md)；原记录仍保留提示词归属和不使用弹窗的理由。

通用产物选择器识别 `.tmp-check.py` 等点前缀临时名称，仅从展示中隐藏，不删除文件，也不排除正常交付的源码，与[正式产物选择](2026-09-30-final-deliverable-selection.zh.md)一致。

## Alternatives considered

**纯内网模式拒绝所有互联网安装。** 用户明确允许网络可达时下载；部署标签不是下载失败的证据。

**只在用户消息中要求模型解释。** 普通请求没有专门测试话术时，Shell 失败反馈也需要生效。

**强制弹窗或固定助手回复。** 既有工具结果已承载持久化且模型可见的事实；简短回复仍通过模型指引完成，不改变官方循环。

## Consequences

识别器尽力分类，无法覆盖所有自定义报错。仅依赖源未找到包不能证明连接被拒绝。安装成功和互联网模式的输出保持不变。针对性测试覆盖五种 Shell 与输出工具名称、分类、权限反例、模式切换、卸载及 Loader 组合的 PowerShell 结果快照。真实模型措辞仍需桌面验收；提示词不保证固定调用次数。临时文件过滤只影响展示。
