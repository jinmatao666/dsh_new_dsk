# Agent Note：持久化知识库文件夹

Status: implemented

[English](2026-11-12-knowledge-empty-folders.md) | 中文

## 决策

OneAPI 将空文件夹路径与 RAGFlow 文档分开保存。桌面端按名称合并已保存目录和上传文档路径。选择文件夹只打开该目录，可通过路径导航返回上级。上传和新建文件夹使用当前目录，使显示内容与上传目标一致。创建目录要求调用者拥有未归类个人库。HTTP 接口校验名称并要求其在库内唯一；删除知识库时同时删除目录。

只有所有者能删除已保存的空文件夹。后端检查子文件夹及结合相对路径的实时 RAGFlow 文档；读取文档失败时拒绝删除。删除只移除一条目录记录，不操作文件。有内容的目录必须先手动删除文件和子文件夹。

拒绝占位文档，因为它们会改变文件数量并可能进入检索。拒绝浏览器本地存储，因为目录组织属于授权知识库，应跨设备共享。

本决策部分取代[仅个人库上传](2026-11-06-desktop-knowledge-upload-personal-only.zh.md)中隐藏文件夹入口的规定，其可见性规则继续有效。[包 README](../../../../packages/wanwei/knowledge-base/README.zh.md)负责说明菜单行为。

## 验证

客户端测试覆盖目录选择、当前目录内的相对路径上传、路径导航、重新挂载后的空目录持久化和重名。Host 测试覆盖认证路由与非法参数。Go 测试覆盖持久化读取、重复与非法名称，以及他人或公共知识库。
