# Agent Note: 创建用户时选择角色

Status: implemented

[English](2026-09-11-user-creation-role-selection.md) | 中文

## Problem

管理员需要在创建用户时明确指定业务角色，而不是依赖隐式默认值。

## Decision

后台创建用户表单提供两种角色：普通用户和超级管理员。

只有超级管理员可以选择并创建另一个超级管理员。

服务端在此创建路径中只接受这两种角色；对既有调用方遗漏角色的请求按普通用户处理，并拒绝其他角色创建超级管理员的请求。

既有管理员账号及其模块权限保持不变。

## Alternatives considered

在创建表单中提供现有管理员角色。

管理员访问权限已由专门的后台权限管理页面维护，而用户要求的创建流程只有两种业务选择。

仅依赖浏览器隐藏超级管理员选项。

构造请求可以绕过浏览器，因此服务端必须执行相同限制。

## Consequences

新账号获得明确的普通用户或超级管理员角色。

创建弹窗保持简洁，非超级管理员不能创建特权账号。
