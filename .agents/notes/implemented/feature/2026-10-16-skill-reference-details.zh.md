# Agent Note: 技能引用详情与示例

Status: implemented

[English](2026-10-16-skill-reference-details.md) | 中文

## 问题

暂存技能标签点击后会移除引用，会话编辑器标签则缺少移除按钮。管理员无法为桌面详情页提供使用示例。

## 决策

两种状态均使用独立的名称按钮和右上角移除按钮。编辑器通过带类型的浏览器事件 `dsh:reference-open` 传递 source/ref；技能市场负责跳转并解析平台、个人及当前会话的本地元数据。关闭详情保留草稿。移除仅删除一个引用，不删除安装文件。OneAPI 服务通过技能元数据提供 `usage_example`；桌面在描述下按转义纯文本展示并保留换行，空示例不展示。

## 考虑过的替代方案

同时用整个标签跳转和删除会让操作含义不明确。将市场跳转写入通用编辑器会耦合独立功能插件。从可执行 SKILL.md 读取示例会混合用户示例和模型指令，并让简单的元数据调整依赖包内容修改。

## 影响

定向测试覆盖选择工作区前的独立操作，以及选定后的真实 Lexical 移除，验证文字和其他引用保留。桌面 CLI profile 浏览器回归只替换外部后端和原生接口，检查服务端示例及暂存引用跳转、移除。OneAPI DTO 测试通过；SQLite 持久化测试需要当前 Windows 终端不具备的 CGO。示例展示需要同时更新后台和桌面端。不改变模型提示或引用序列化。
