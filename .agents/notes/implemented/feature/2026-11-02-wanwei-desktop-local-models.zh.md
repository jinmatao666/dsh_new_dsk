# Agent Note: 万维桌面端支持用户配置本地模型服务

Status: implemented

[English](2026-11-02-wanwei-desktop-local-models.md) | 中文

## Problem

万维桌面端原本只显示 OneAPI 后台授权的模型。通用模型设置页被禁用，登录和退出时又会整体替换模型服务配置，因此用户无法保留自己添加的模型服务。

## Decision

万维产品层启用通用模型设置页，并关闭通用首次引导。OneAPI 只管理 `dsh-server` 路由：设置页展示该路由及已授权模型清单，但不提供本地编辑和删除操作。其他模型服务和凭据归桌面端用户管理。对话框中的模型菜单可以打开设置页，并继续按服务分组展示模型。

认证过程只修改 `providers.dsh-server`。登录时保留用户已选择的本地默认模型，退出时只移除后台模型路由。同一个设置命名空间中的后台配置与用户配置因此分别由各自的管理方维护。

## Alternatives considered

**另做万维专用模型配置页：**未采用。通用配置页已经支持 OpenAI 兼容接口、凭据、模型清单和删除模型服务。

**继续整体替换模型服务配置：**未采用。每次登录或退出都会清掉用户添加的服务。

## Consequences

用户仍需登录万维账号才能进入桌面端。本地模型的 API 密钥通过现有桌面凭据服务保存。登录后，已选择的后台模型可能随授权清单刷新而切换到后台默认模型；已选择的本地服务会保留。
