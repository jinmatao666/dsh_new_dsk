# Agent Note: 桌面端内外网切换预设

Status: implemented

[English](2026-11-09-desktop-network-presets.md) | 中文

## Problem

切换部署模式时，旧逻辑不会恢复管理员保存的互联网选项，也不会统一应用约定的内网默认值。

## Decision

后台只在进入内网模式时应用预设，保留互联网功能开关。预设开启自动化，隐藏连接器和可选业务入口，启用 Python wheel 离线包。桌面登录和连接器调用检查当前策略，浏览器和网页读取检查内网访问目标。

## Alternatives considered

**在设置表单里应用预设。** 直接调用接口可以绕过表单，造成模式和配置不一致，因此切换规则由后台执行。

## Consequences

管理员可以在内网运行期间临时调整设置，重新进入内网时恢复预设。模型配置、业务页面地址、上传文件和账号数据保持不变。应用策略仍需要现场网络边界配合。
