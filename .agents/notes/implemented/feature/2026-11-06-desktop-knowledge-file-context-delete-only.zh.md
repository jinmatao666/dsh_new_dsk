# Agent Note: 桌面知识库文件右键仅个人库删除

Status: implemented

[English](2026-11-06-desktop-knowledge-file-context-delete-only.md) | 中文

## 问题

桌面知识库文件右键菜单对所有选中库提供移动、复制与删除。调用者可从「公共知识库」与「订阅知识库」发起转移，且个人库仍暴露移动与复制，尽管产品只要求个人库保留删除。

## 决策

文件右键操作通过 `libraryIsDesktopPersonal` / `libraryAllowsDesktopFileDelete` 按侧栏分组限定（与 [桌面知识库上传仅限个人库](2026-11-06-desktop-knowledge-upload-personal-only.zh.md) 相同的未归类个人库行）。在「个人知识库」下右击选中文件且仅显示删除；在「公共知识库」与「订阅知识库」下右击不打开菜单、不提供任何文件操作。桌面端移动/复制对话框已移除；Host 的 `copy` / `move` API 仍保留给其他调用方。

## 考虑过的替代方案

**个人库保留移动与复制，仅在公共与订阅隐藏。** 否决；产品要求个人库也去掉这两项。

**按任意 kind 的 `owned_by_viewer` 放开菜单。** 否决；侧栏公共与订阅分组即使浏览到自己拥有的行也不得有文件操作——规则按分组。

## 后果

个人库保留带确认的删除。公共与订阅选中时不出现右键菜单。关闭菜单（点空白、滚动或窗口缩放）或取消删除确认时，同步取消右击带来的选中高亮。针对性 Client 测试覆盖个人库仅删除、关闭菜单清选中，以及公共与订阅选中时菜单缺席。
