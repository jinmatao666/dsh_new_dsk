# Agent Note: 万维后台启动进程归属

Status: proposed

[English](2026-09-27-wanwei-sidecar-startup.md) | 中文

## 问题

桌面 stdout 读取器收到就绪地址后退出，Node 后续仍可能写入已关闭的管道。启动错误也直接丢弃子进程句柄而没有终止进程，可能在 Windows 上占用运行时文件，并在 macOS 或 Linux 上遗留未使用的服务。

## 提案

持续读取 stdout 直到 EOF，就绪地址只通知一次。启动失败时先终止并等待直接子进程退出，再返回原始错误。该产品行为保留在万维桌面目录。

## 考虑过的替代方案

**只延长启动超时。** 无法避免管道关闭，也无法回收失败进程。

**错误时丢弃子进程句柄。** Rust 子进程句柄被丢弃时不会终止进程。

## 验收标准

回归测试验证就绪后持续消费输出、接收端断开仍继续读取、就绪只通知一次，并用真实测试子进程验证失败启动已回收进程。Windows 测试与 macOS/Linux 发布版冒烟仍是分别需要的证据。

## 风险

直接子进程回收不等于进程树归属。带有运行中后代任务时退出托盘应用，仍需单独的平台验证。原生跨平台运行验收尚未完成。
