# Agent Note: 原生导入目标归属

Status: proposed

[English](2026-09-27-wanwei-import-ownership.md) | 中文

## 问题

检查可用目标名称不等于占用该名称。随后执行原生复制可能覆盖并发创建的文件；目录创建失败后由调用方清理目标，也可能删除已有目录。

## 提案

独占创建目标文件，并向持有的句柄复制源数据。目录清理放在复制函数内部，仅在独占创建目录成功后执行。Windows 写入失败时先关闭输出句柄，再删除不完整文件。

## 考虑过的替代方案

**再次检查目标是否存在。** 重复检查仍不能消除写入前的竞争。

**失败时一律删除目标。** 目标可能属于其他操作。

## 验收标准

测试验证复制拒绝冲突时保留已有文件和目录、失败时清理新建的不完整目录，并保留中文与空格名称。macOS 和 Linux 原生拖入行为仍需设备测试。

## 风险

重名冲突明确失败，不静默重试。这不是批量事务导入，后续条目失败时先前完成的条目可能保留。
