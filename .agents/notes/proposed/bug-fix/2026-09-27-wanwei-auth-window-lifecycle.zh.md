# Agent Note: 桌面认证与隐藏窗口生命周期

Status: proposed

[English](2026-09-27-wanwei-auth-window-lifecycle.md) | 中文

## 问题

状态 RPC 与登录、退出重叠，可能在新操作完成后返回旧快照。macOS 关闭时隐藏窗口还需要处理 Dock 重新打开事件，单纯的托盘恢复处理器收不到该事件。

## 提案

万维控制器跟踪认证变更与刷新请求顺序。过期或已取消的刷新不发布状态或离线错误。macOS Reopen 事件恢复主窗口，正常 Exit 事件停止直接后台进程。

## 考虑过的替代方案

**禁用焦点刷新。** 会失去有用的会话校验，也不能修复已经在途的响应。

**只允许从托盘恢复。** 无法支持正常的 macOS Dock 操作。

## 验收标准

控制器测试覆盖迟到的刷新成功、迟到错误、取消，以及登录被后发退出取代。Windows 原生编译与已有桌面回归通过。Dock 恢复与系统退出需要真实 macOS 验证。

## 风险

客户端顺序控制不会串行化远端 Host 操作。正常退出清理不覆盖强制终止，也不保证后代进程树回收。
