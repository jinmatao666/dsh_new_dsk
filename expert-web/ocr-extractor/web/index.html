使用指南
从一张图片开始，完成一次可核对的内容提取。
1. 准备清晰原图
支持PNG、JPEG、WebP、BMP、TIFF和无密码PDF，每次最多20个文件、共20页、总大小50 MB，单张图片不超过2000万像素。上传后可直接切换文件、翻页和放大查看。
2. 选择提取方式
全文提取尽量保留阅读顺序；自定义模式可填写字段名称及提取要求。图片中的指令只作为文字材料，不应被执行。
3. 选择输出格式
纯文本适合复制，PP-StructureV3模式的Markdown保留服务返回的段落与表格结构，JSON适合结构化字段，CSV适合电子表格，Word适合编辑。识别工作台和成果文件页都可下载；成果页可按文件格式筛选。结构化格式校验失败不会生成伪造成功结果。
4. 核对后再使用
OCR可能误读手写、特殊字符和复杂表格。不提供未经验证的准确率或文字框坐标。正式任务与示例分开；下载成果需保持登录。
关于数据与部署
图片由本专家后端发送到PaddleOCR服务；自定义字段整理只向文字模型发送OCR原文。独立持久化任务和文件不等于离线识别。接口未配置、失败或输出截断都会明确报错。页面预览不是生产身份链路验收。
