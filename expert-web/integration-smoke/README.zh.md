# 专家网页接入验证站

[English](README.md) | 中文

这是独立的 Node 22 网站，不属于 DSH pnpm 工作区。它以真实文本文件生成校验报告，用于验证平台票据、用户记录隔离、文件处理和成果下载；不是六个正式专家之一。服务使用内存会话和任务，仅适用于接入联调，重启后记录会消失，不能作为生产任务存储。

在本目录运行 `node --test`。配置 `.env.example` 中列出的环境变量后运行 `node server.mjs`；实际部署应通过 HTTPS 反向代理公开服务，并由平台签发短时一次性票据，以 `#ticket=...` 打开页面。网页从 URL 片段读取票据并立即清除，然后由本站后端调用 `EXPERT_PLATFORM_REDEEM_URL` 核验。提供方凭据只保存在本站服务端，不能进入网页或仓库。平台核验接口完成前，本站不能完成真实登录联调。使用说明页的“检测桌面原生桥”会尝试调用只读的技能列表命令，不显示列表内容，用于同窗子 WebView 实机检查。

单目录搬迁验证：只复制 `integration-smoke/` 到空目录，运行 `node --test`、`node server.mjs`；不需要 DSH 根目录依赖、脚本或资源。生产使用前还需持久化任务、反向代理安全配置和实际平台接口联调。
