# 图像变化发现专家

[English](README.md) | 中文

## 处理流程

支持视觉的 Chat Completions 模型接收有序的前后两张图片。可选对齐后，先发现语义变化事件，忽略阴影、季节色差与瞬时小目标，再逐项调用模型定位，返回0至999归一化坐标。连续变化使用区域框；同类别、同变化类型的高度重叠重复框会抑制。坐标是模型估计，需人工核对。无效、截断或无法定位的响应明确失败，不使用像素差异或网格补造检测框。

矩形框模式直接展示模型框，不调用SAM3。精准模式将候选框交给SAM3生成真实掩膜，消失目标使用前期图片。一项事件保留一条结果，不再按掩膜碎片逐个拆分。JSON与CSV包含变化类型、类别和描述；可下载模型发现与定位依据、标注图、对齐前期图、对比图及诊断热力图。框模式不声称计算了真实变化面积，也不输出伪造掩膜。

## 部署

在私有 `.env` 配置 `EXPERT_MODEL_URL`（完整Chat Completions接口）、`EXPERT_MODEL` 和 `EXPERT_MODEL_KEY`。模型必须支持双图输入，纯文字模型不够。允许回环HTTP；远端HTTP需设置 `EXPERT_ALLOW_HTTP_MODEL=1`。请求使用服务端凭据，限制响应大小并禁止跳转。模型可用性和真实识别质量仍需目标服务器验证。

精准模式另需 `SAM3_URL`、`SAM3_KEY`，现有 `/v1/images/segment` 服务使用 `SAM3_API=deployed_v1`；旧 `/segment` 接口使用 `adapter_v1`。无兄弟目录源码导入。使用 `docker compose -p wanwei-image-change-detection up -d --build` 仅重建本专家，保留私有配置、数据卷 `wanwei-image-change-detection-data`、回环端口3314、网关 `/experts/image-change-detection/` 和Cookie身份。Dockerfile已包含独立语义识别模块。

## 验证与限制

执行 `python -m unittest -q test_vision test_semantic` 和 `node --check web/app.js`。HTTP替身覆盖真实工作子进程、双图输入、候选定位、真实测试掩膜、下载和用户隔离；单元检查覆盖去重、坐标缺失、无效数字及截断响应。这些测试不证明真实视觉模型准确率、SAM3质量、GPU性能或正式部署。发现阶段最多24个候选，每项最多8个位置，超量明确失败而非静默截断。同尺寸图片未找到可信校正时按已配准材料在原位置比较，并在结果中记录此假设；不同尺寸图片仍需可信变换。本地取消后，远端推理可能继续。

## 工作台与成果管理

任务名留空时使用前期图片名及 `_年月日时分`。工作台默认进行可信的位置校正；同尺寸材料在无法可靠校正时按已配准图在原位置比较，并明确记录采用的方式。精准分割勾选框与文字同行。数量按变化事件统计，不按框或轮廓碎片统计；框模式隐藏面积指标。精准模式使用彩色掩膜与轮廓，扩张、缩减和修改比较两期掩膜，总面积对重叠像素去重；同类同类型且掩膜高度重合的结果保守合并。图片切换按钮位于坐标表下方、图片正上方。

下载显示名和实际文件名统一使用中文。紧凑下载区支持单文件及包含本任务全部实际成果的ZIP。成果页每个任务一行，按完成时间倒序，支持下载ZIP和删除成果。删除移除输出目录及链接，保留原图和任务记录，可重新分析；已删除结果返回HTTP 410。已有数据库补充成果删除及完成时间字段，不替换历史记录。ZIP按需生成，源文件合计限120 MB。
