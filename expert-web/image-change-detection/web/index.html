使用指南
变化发现专家
准备材料
上传同一区域、视角接近的两期图片，顺序为前期、后期。系统自动对齐后比较共同范围；对齐失败会提示重新选择材料。明显不对应的图片不适合比较。
如何读坐标
左上角是原点，数值范围0～1。矩形为[x_min, y_min, x_max, y_max]。变化坐标统一对应后期分析图；自动对齐时同时提供已对齐的前期图。 轮廓为近似点列，二值mask.png保留精确像素范围。
结果与限制
检测的是疑似视觉变化，不推断变化原因。阴影、季节、光照和视角变化可能误报。精准模式根据SAM3轮廓细化结果；扩张、缩减和修改比较前后轮廓，结果仍需人工核对。 未检出不代表一定不存在，参数和图片质量会影响结果。
登录与下载
从Buddy卡片进入，身份过期后重新打开。每个用户只能访问自己的任务和文件；取消会停止本地任务，但远程服务可能仍在计算。
