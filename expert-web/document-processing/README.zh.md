任务轮询仅在首次返回或任务数据变化时重绘页面；准备表单打开期间只更新缓存，不替换当前表单。较早请求的响应不能覆盖较新成功请求的数据；手动结果刷新使用相同的顺序保护。

任务、预览或成果请求返回 HTTP 401 时，工作台锁定并清除任务和材料缓存；迟到响应不能恢复页面。下载过程中登录失效会取消成果读取，不再调用原生保存。需关闭 Tab，从桌面专家库重新打开以交换新票据；这些前端检查不撤销提供方已经接收的任务。

Compose 固定容器监听端口，使其与仅绑定本机的端口映射一致；修改 `.env` 中的 `PORT` 不会改变该端口。如需其他本机代理端口，修改 `ports` 的宿主机端口；公网 HTTPS 地址通过 `EXPERT_PUBLIC_URL` 配置。

## 独立迁出验证

网站公网地址与平台票据核验地址支持 HTTP 和 HTTPS。仍建议 HTTPS：HTTP 会使票据、提供方凭据、Cookie 和任务数据面临窃听或篡改。来源检查仍包含协议、域名和端口，核验拒绝重定向。从只支持 HTTPS 的代码升级时，除重部署网站外，还需重新构建平台镜像和桌面安装包。原有 HTTPS 代理示例仍可使用；此前只支持 HTTPS 的表述以此项为准，并不意味着 HTTP 已有加密保护。

运维可执行 `python deployment.py` 检查配置和本地处理依赖；只输出检查名及通过状态，不打印密钥或接口地址。`/healthz` 验证 HTTP 与数据库可用，`/readyz` 检查所有已提供功能的必要配置，未配置返回 503；后者不是远程服务真实连通性测试。Dockerfile 配置了存活检查。

在已更新的桌面专家 Tab 中，成果下载通过 `save_expert_artifact` 打开原生“另存为”窗口，由用户选择目标路径和确认覆盖。网站不能提供本机路径。接口校验成果字节（最大 128 MB）、文件名和原始扩展名，返回已保存路径，取消返回 null。普通浏览器使用浏览器下载；三平台桌面交互仍待验收。

在本目录执行 `python verify_portability.py`。脚本只复制本专家目录到临时位置，排除本地数据和凭据，再创建全新虚拟环境、安装自身依赖并执行 Python/Node 测试，不读取 DSH 根目录或其他专家代码。Node.js 需要已安装。

`python verify_portability.py --deployment` 还要求 Docker Compose 配置校验和镜像构建；缺少 Docker 会明确失败，不将未执行的部署检查算作通过。容器实际启动、HTTPS、真实业务接口和桌面同窗联调仍须在目标环境验收。

工作台已接入自有旧版图标和背景，任务列表可打开详情，成果文件独立汇总。原始文件名仅保存为任务元数据；服务器上传路径始终使用内部编号。已有数据库会自动增加文件名字段，不复写旧记录；历史记录没有原名时显示原存储名称。视觉逐状态验收仍未完成。

本项目独立拥有网页工作台、身份会话、SQLite 持久任务、文本提取、摘要和版本对比，不引用 DSH、OneAPI 或其他专家源码。真实模型联调、容器实跑和旧版视觉验收尚未完成，不可正式上架。

支持 DOCX、PDF、XLSX、XLSM、UTF-8 TXT/Markdown/CSV/TSV/JSON/YAML。DOCX 保留正文段落与表格顺序；Excel 读取已保存的值，不执行宏或计算公式；扫描 PDF 没有文字时拒绝处理并提示 OCR。单材料 20 万字符、PDF 300 页、Excel 10 万单元格、XML 包解压 64 MB 上限。

对比严格按文件顺序：第一份原始版本，第二份新版本。成果包含真实 DOCX、可视化逐行 HTML、Markdown 与 JSON。不比较排版、图片、批注或修订痕迹。

任务工作进程将上传原名作为仅用于展示的来源标签传给摘要和对比。模型请求和下载报告保留原名；读取文件使用内部编号路径。没有原名的旧任务使用其存储名称。来源名称列表无效时拒绝发布成果。

对比表单保留旧版的对比范围和补充要求。任一要求非空时，服务端使用已配置模型分析两个完整版本，材料合计不超过 6 万字符。模型分析在网页、DOCX、Markdown 和 JSON 中单独标注，不改变确定性差异统计。缺少模型配置或调用失败会使任务失败，不生成替代分析。两个字段均留空时仅执行精确文字差异对比。

摘要通过本专家服务器配置的 HTTPS OpenAI-compatible chat completions endpoint 调用模型，配置 EXPERT_MODEL_URL、EXPERT_MODEL 和 EXPERT_MODEL_KEY。不复用桌面模型令牌，不向网页传递密钥。缺少配置、模型失败或输出截断均明确失败，不生成演示报告。摘要材料合计不超过 6 万字符，超过时拒绝，不静默截断；生产部署须选择能容纳该请求的模型。

## 独立服务和部署

任务成果页采用旧版工作台的单一状态与成果容器、流程步骤和任务标题。对比统计及按新增、删除、修改配色的段落保留在容器内，最多预览 100 项差异，完整文件仍可下载。新增模型分析与确定性统计分开展示。参数保留在结果下方的折叠详情中，未完成或失败任务不发布下载链接。远程服务器任务目录不作为本机桌面路径暴露。

摘要预览以单栏章节展示段落、加粗重点、列表和 Markdown 表格。来源上标和来源文件标记转换为可读引用；其他 HTML 被转义，链接不激活。Word 导出支持标题、加粗、列表和表格。已有 Word 文件须重新生成任务才能取得这些格式；已有 Markdown 预览使用当前渲染器。预览最多 3 万字符，截断时明确提示。

记录行除名称、时间、输入数量和状态外，还标明任务类型。空记录和空成果页提供新建任务按钮，按旧版首工具入口打开文档摘要准备页。

通过环境变量注入 `.env.example` 所列配置后运行 `python server.py`；程序不自动加载 `.env`。使用容器时将示例复制为 `.env` 并填入真实配置，再执行 `docker compose up --build -d`。仅启动一个服务实例，HTTPS 代理配置见 `nginx.conf.example`；本机没有 Docker，容器文件尚未实跑验收。基础镜像上线前固定到审核过的 digest。

每次最多 30 个文件、总计 32 MB，摘要进一步限制为 10 个文件。任务在专家自身数据目录内保存，不写入平台对话。子进程只通过标准输入取得显式配置的模型访问参数，不继承平台提供方凭据。取消任务不发布成果，并终止本地工作进程树；远程模型已经接收的请求仍可能继续在服务端运行。Linux 超时也会回收整个进程组。默认保留 30 天终态任务，启动和提交新任务时清理；运维须配置磁盘监控、容量上限与备份。网页参数、目录来源、账号隔离和真实对比文件下载已有 HTTP 测试。
